依据：设计文档 2.1 总表第9章一行（露伴宅、隧道、公路、医院、川尻家阁楼；小游戏 骰子；第 14 战公路之星「隧道、追车、医院」三段；插曲 阁楼的猫草）。
设计文档的分章详情只写到第6章，第9章没有地图表，下面的 key、宽度、锚点、开关层由背景线程定，第9章剧情线程照用。
脚本：`tools/art/p4_bg_ch9.py`（`python3 第四部/tools/art/p4_bg_ch9.py [key …]`），元数据 `assets/_meta/bg_ch9.json`，
打包成 `游戏/data/img_bg_ch9.js`（pack `ch9`，进第9章时 `playFrom` 自动加载）。

## 1. 一览

| key | 宽 | 用在 | 能切换的层（`stage.state[key]`） |
|---|---|---|---|
| `rohan_parlor` | 480 | 露伴宅客厅：未起隆、仗助和露伴的骰子小游戏；结尾露伴家着火 | `fire`：1 = 左边的门和窗帘烧起来、地板一溜火、黑烟、整屏橙色（数字 = 罩色浓度倍数） |
| `route_tunnel` | 960 | 国道隧道，第 14 战段 1（右端 x 912 起是出口外面的傍晚） | `room`：1 = 墙上开出公路之星的“房间”（亮灯的门洞，门牌 ROOM） |
| `national_road` | 960 | 海边国道，第 14 战段 2 三车道追车 | `speed`：卷动速度倍数（不设 = 1 一直在卷，0 = 停住，2 = 更快）；`pm`：傍晚罩色 |
| `hospital_corridor` | 640 | 医院三楼走廊，第 14 战段 3 找病房 | `pm` |
| `hospital_room` | 320 | 裕也的病房（304），战后 | 无（本身就是傍晚） |
| `kawajiri_attic` | 320 | 川尻家阁楼，插曲“阁楼的猫草”（早人） | `lamp`：1 = 拉亮梁上的灯泡 |

一直在动、不用管的：露伴宅吊灯微闪，隧道钠灯微闪，国道四层自己往左卷，阁楼光柱里的浮尘。

`national_road` 的四层（天、海、海边礁石和黑松、近处护栏 + 路面）都是 `wrap`，`vx` 分别是 6 / 36 / 120 / 260 px/s，
引擎按 `stage.state.speed` 乘上去。追车时人物自己站在原地跑、背景卷；要停车演对白就 `state.speed = 0`。

## 3. 用法示例

```js
ST.parlor_ch9 = base('parlor_ch9', 'rohan_parlor', 480, { music: 'calm', state: {} });
G.world.stage.state.fire = 1;          // 骰子打完、露伴家着火
ST.tunnel_ch9 = base('tunnel_ch9', 'route_tunnel', 960, { music: 'tension', state: { room: 0 } });
G.world.stage.state.room = 1;          // 墙上出现“房间”
ST.road_ch9 = base('road_ch9', 'national_road', 960, { music: 'battle', state: { speed: 1 } });
G.world.stage.state.speed = 0;         // 停下来说话
```
