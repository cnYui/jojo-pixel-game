## 3. 用法示例

```js
ST.home_ch2 = base('home_ch2', 'hirose_living', 320, { music: 'tension', state: { door: 0 }, obstacles: walls(52, 312, 320) });
// 玉美碰到门：
G.world.stage.state.door = 1;
// 道口的假警报（栏杆不放，灯也可以不闪：原著只有声音）：
G.world.stage.state.alarm = 1;      // 要灯闪就开
G.world.stage.state.gate = 1;       // 真有火车时才放栏杆
```
