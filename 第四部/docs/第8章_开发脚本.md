# 第8章　吉良家旧宅 / 原子心之父 —— 开发脚本（2026-11-03）

依据：设计文档《JoJo 第四部〈不灭钻石〉像素剧情游戏 · 剧情设计》总表第8章那一行、2.2 队长表、2.5 第 12 / 13 战（https://claude.ai/artifact/1wH9fViMTRBgfL8HaeUz1r ），原著 365–377 话三个篇章（原子心之父、吉良吉影的新生活、猜拳小子来了）。设计文档第8章只有总表一行，这份照原著补全；原著细节没逐格核的地方写在第 6 节待核。
实现：`游戏/story/p4_ch8.js`（剧情、地图、自由走动）、`游戏/story/p4_ch8_fights.js`（第 12、13 战）。
背景：第8章背景线程画的四张（交接说明 `docs/第8章_背景.md`），加上序章的 `morioh_map`。
台词都是新写的，不照搬原句。每句不超过 2 行、56 字。表情名只用 normal / smile / rage / shock。

## 0. 给实现的人

- 角色 cid：`josuke` / `crazyd`、`jotaro4` / `starplat`、`koichi`、`yoshihiro`（吉良吉广，照片里的老人，本章画）、`oyanagi`（大柳贤，本章画；Boy II Man 不画成人形，只用替身卡和“被拿走的三分之一”特效）、`shinobu`（川尻忍，本章画）。
- 别章负责的人：露伴 `rohan`（第5章）、乔瑟夫 `joseph_old`（第4章）、换脸后的吉良 `kawajiri`（第7章）。它们合进来之前用本章的临时占位 `ph8_rohan` / `ph8_joseph` / `ph8_kosaku`：`p4_ch8.js` 的 `cast()` 先找正式 cid，没有才用占位，合并后自动换。静（`shizuka`，第4章）是透明的，本章不画、不 spawn，只用对白和“看不见的手”的小特效。
- 早人这一章不露面：只在门后说一句话，结尾的摄像机是背景层 `cam`。他的人物第9章画。
- 克制：吉广的“刀”只是挥过来的一道白光，不画刀刃和伤口；照片空间里的伤只用 HUD 掉血表示。猜拳输了被拿走的是替身的“三分之一”，画成替身卡缺一角，不画肢体缺失。
- 伤害系数 ×1.1（第8–10章）。仗助 HP 130、承太郎 130（照序章）。
- 队长：旧宅那段仗助 ⇄ 承太郎；车站那段康一、乔瑟夫、露伴（Q 换），第 13 战只有露伴。亿泰本章不出场（设计 2.2 标的 ○ 是“能当”，原著这三篇里没有他）。

## 3. 第 12 战 原子心之父（b12_atomheart）

仗助 ⇄ 承太郎（Q 换），1 段，伤害 ×1.1，能输（从这场重来）。场地 `photo_x` [150, 510]。

- 吉广在三个相框之间钻来钻去：遗照 `portrait`、桌上相框 `table_frame`、电视屏幕 `tv_screen`。在相框里时打不到（拳头穿过去，头上冒「打不到照片！」）。
- 他从相框里探身出手：W1 预警 0.6 s 后，近身挥一道白光（8 伤），远了就扔茶杯（6 伤，L 能挡、精准格挡打回去）。出手之后 1.2 s 他整个人露在相框外面：这时 J 打中他 → 他摔出相框，倒在地上 4 s（`down`）。
- 拍照：他倒地时画面上出取景框（以他为中心宽 72）。换成承太郎（拿着拍立得）按 U「拍照」：取景框里只能有他一个人。仗助还站在框里 → 拍出来两个人，吉广笑着钻回相框；仗助走开、承太郎站在框外 → 拍到他一个人 → 胜利。
- 倒地时队友不再自己乱跑（AI 定在原地），所以玩家要自己把位置让开：用仗助打下来就先走开再换人，或者直接用承太郎打。
- 第一次把他打下来时停一下，承太郎说出拍照的办法。
- 打完收尾见节拍 5。

## 4. 第 13 战 Boy II Man（b13_boyiiman）

露伴一个人，先赢 3 局；露伴输 3 局（替身被拿光）就失败重来。不打架、不扣血，HUD 是比分和“天堂之门剩下几分之几”。

- 键位：← 石头、↑ 剪刀、→ 布。画面中间两只大手；倒数「石头——剪刀——布！」三拍，第三拍前后 0.35 s 内出手，早了是“先出”、晚了是“后出”，都算输（大柳：「后出是犯规哦～」）。
- 读习惯：第二拍时大柳的手会先“动一下”（0.4 s 的小动作，三种各不相同：攥紧 = 石头、两根手指一翘 = 剪刀、手掌一张 = 布）。这是真的习惯。
- 心理战：开局前大柳会说“我下一把出 X”。第 1、2 局他说的是真的；第 3 局起一半是假的，以小动作为准。
- 第 1 局之前不讲习惯（教学：输一局也正常）；输过一局以后露伴会说「……他出手前，手先动了」，同时出提示。
- 静：第 3 局开始前静在乔瑟夫怀里打了个喷嚏，露伴的手一下子变透明了。大柳：「看不见你的手，不算！」重来这一局。露伴：「……我拒绝别人帮忙。」（只是插曲，不影响胜负）
- 赢了见节拍 9。

- 原著里吉广最后是怎么被封住的（游戏用“拍一张只有他自己的照片”，这是设计文档 2.5 定的规则）；他是在旧宅里就带着箭跑了，还是之后才去拿的。
