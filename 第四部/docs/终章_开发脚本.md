依据：设计文档《JoJo 第四部〈不灭钻石〉像素剧情游戏 · 剧情设计》的「终章」一节（https://claude.ai/artifact/1wH9fViMTRBgfL8HaeUz1r ），原著 428–439 话（TV 动画第 37–39 集）。
实现：`游戏/story/p4_final.js`（剧情、地图、尾声）、`游戏/story/p4_final_fights.js`（第 19 战五段），写法照序章的 `p4_prologue.js` / `p4_pro_fights.js`。
背景：终章背景线程画的七张（交接说明 `docs/终章_背景.md`），加上序章的 `morioh_map`。
台词都是新写的，不照搬原句。每句不超过 2 行、56 字。表情名只用 normal / smile / rage / shock。

## 0. 给实现的人

- 引擎、键位（J K L U Q E）、对话框、名牌、替身卡、VS 卡、To Be Continued、存档全部用现成的。终章不出 To Be Continued，结尾出「完」和职员表。
- 伤害系数：段 A–C ×1.2，段 D、段 E ×1.3（设计文档 1.2）。吉良的血：段 A–C 共用一条 1500，段 D 换一条 1800。
- 队长：段 A–C 只有仗助（早人跟着、灰）；段 D 亿泰回来以后能 Q 换亿泰；段 E 先康一后承太郎（剧情自动换）。
- 克制（设计文档 4.6 和终章“克制处理”）：亿泰被打中、早人身上的炸弹、挡空气弹都只有白光和剪影；仗助的血画成粉色的修复光点；
  邻居那段不演；吉良之死 = 救护车倒车 → 黑屏 + 刹车声；铃美给他看的“伤口”不演；阿诺德咬的是袖子；被拖进小路只画手的影子。
- 吉良不能操作（1.2 第 7 条）。

## 3. 第 19 战　杀手皇后 + 猫草（`b19_kq_*`，五段）

吉良的本体：`e_fin_kira`（kit），杀手皇后站在他身前出拳（替身 `fin_kq` 或正式版）。每段是一场 `S.fight`，就是重来点。

### 段 A　雨中的街口（`b19_kq_a`，corner_fin，仗助，亿泰 AI）

| 项 | 值 |
|---|---|
| 吉良的招 | 杀手皇后冲拳（预警 0.45 s，14）；触爆（杀手皇后摸一下路面或垃圾桶 / 邮筒 / 石子：东西亮一圈粉光，2 s 后炸，半径 40 px，18） |
| 亿泰（AI） | 跟仗助一起打；每 9 s 用一次“拉近”：吉良被拽到仗助面前 22 px（提示「亿泰把他拽过来了！J 连段！」） |
| 猫草 | 吉良的血 ≤ 1200：过场「……该你出场了，猫草。」把猫草收进杀手皇后的肚子 → 之后每 3.5 s 放一颗空气弹 |
| 空气弹 | 看不见的泡泡，慢慢飘向仗助（速度 32）；雨滴绕开它，所以泡泡的轮廓只有一圈淡淡的水线（提示「雨滴在半空绕开了……那里有东西！」）；碰到就炸（25，半径 40 px）；J 打中也会炸 |
| 结束 | 猫草出场后撑 40 s（HUD 计时）→ 过场：亿泰被打中倒下 |
| 输 | 仗助 HP 0：照常“再来一次” |
| 实测调整 | 猫草出场后的空气弹最多 2 颗、速度 28、伤害 18；吉良出拳间隔 2.6 s。猫草出过场以后重来直接从猫草那段开始 |

### 段 B　空房子（`b19_kq_b`，emptyhouse_fin，仗助）

| 项 | 值 |
|---|---|

### 段 C　碎片与电话（`b19_kq_c`，emptyhouse_fin，仗助）

步骤式（HUD 三格「碎片」「打火机」「电话」），没有失败：

1. 「J3 打碎花瓶」：站在花瓶旁（`vase`，±30 px）出 J3 → state.vase = 1，地上一摊碎片。
2. 「E 捡一片碎玻璃」→ 自动：仗助把碎片扔出窗外（state.glass = 1）→ 窗外的杀手皇后一拳把它挡开（「哼。」）。
3. 「按住 L 按 J：把碎片修回来！」→ 碎片沾着仗助的痕迹（粉色修复光点），从吉良背后飞回来打中 → 吉良 −150。
4. 「对早人按 E」：仗助：「早人，借你的打火机用一下。」→ 烧早人的外套下摆（只冒烟）→ 外套里飞出一张照片（吉良吉广），往电话那边飘。
   - 吉广（照片里）：「吉影！吉影！他们在——」
5. 电话铃响（state.ring = 1），「3 秒内按 J 抢话筒！」→ 抢到（没抢到就再响一次，不会输）→ 两个选项：「他在二楼窗边」「……」。选第一个：
