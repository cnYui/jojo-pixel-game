依据：设计文档「第4章」一节的场景表（https://claude.ai/artifact/1wH9fViMTRBgfL8HaeUz1r ）。第4章还没有剧情线程，key、宽度、锚点、开关层由这里定，之后第4章的剧情照这份用。

## 3. 用法示例

```js
ST.living_ch4 = base('living_ch4', 'higashikata_tvnight', 480, { music: 'tension', state: { snow: 0, lamp: 0 } });
G.world.stage.state.snow = 1;            // 换台，电视里伸出手
ST.harbor_ch4 = base('harbor_ch4', 'morioh_harbor', 960, { state: { tyre: 0, forklift: 0, ship: 0 } });
G.world.stage.state.forklift = 1;        // 辣妹钻进叉车电瓶，亮 3 s
G.world.stage.state.tyre = 1;            // J3 打爆前轮
G.world.stage.state.ship = 1;            // 段 C 打完，船靠岸
```

## 4. 没画 / 待定

- 摩托、纸箱、快艇、黏地效果、辣妹本体和电光都不在背景里，是道具 / 特效。
- 码头和船只有白天；设计文档写“明天下午到杜王港”，没做傍晚罩色，要的话加一层 tint。
- 叉车那一招的先后顺序设计文档还标着待核，背景只给了“发光”和“轮胎裂口”两个开关，顺序随剧情。
