## 3. 用法示例

```js
ST.kirahouse_ch8 = base('kirahouse_ch8', 'kira_house', 640, { music: 'tension', state: {}, obstacles: walls(8, 632, 640) });
// 拍立得快门 → 照片空间：
G.world.stage.state.photo = 1;          // 战斗场地限在 photo_x [150, 510]
// 战后：
G.world.stage.state.photo = 0; G.world.stage.state.pinned = 1;
G.world.stage.state.box = 1;            // 箱子打开（箭本身是道具）
G.world.stage.state.window = 1;         // 吉广飞走
ST.kawajiri_ch8 = base('kawajiri_ch8', 'kawajiri_house', 640, { state: { dusk: 1 }, obstacles: walls(8, 520, 640) });
G.world.stage.state = { night: 1, cam: 1 };   // 夜里那段 + 结尾摄像机红灯
```
