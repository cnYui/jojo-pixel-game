## 2. 送电铁塔怎么用（竖向地图）

图 320 × 540，世界坐标和平常一样：地面 y 150，图的第 0 行是世界 y −360。往上卷用 `stage.camY`：0 = 看塔脚，−360 = 看塔顶。
引擎加了一个图层类型 `tall`（`engine/bg.js`）：按 `G.cam.y`（= `stage.camY`）把里面的图层整体往下平移，远景 `ky` 0.4、塔身 `ky` 1。
镜头的横向跟随照旧；**竖向不会自己跟人**，剧情 / 战斗要自己设 `G.world.stage.camY`（比如跟着操作角色的 y：`camY = clamp(p.y − 130, −360, 0)`）。

能站的地方（`[x0, x1, y]`，y 是脚底线）：

- 地面：y 150，x 8–312
- 塔身里的水平梁 `beams`：[74, 246, 96]、[83, 237, 42]、[91, 229, −12]
- 三层横担 `arms`（往塔外伸出去）：[48, 272, −66]、[56, 264, −150]、[64, 256, −234]
- 塔顶小平台 `top_deck`：[134, 186, −300]
- 相邻两道之间是交叉斜梁（能爬）；左腿上一路有脚钉

其他锚点：`tower` [160,146]（塔脚中间）、`leg_l` [68,150] / `leg_r` [252,150]、`sign` [48,146]（「私人住宅 请勿靠近」告示）、`path` [60,166]（土路）、
`bucket` [85,146]（从 y −12 那层垂下来的水桶）、`tent` [130,42]（丰大的蓝帐篷）、`stove` [182,42]（炉子水壶，旁边木箱和收音机）、
`tank` [177,−12]（水箱）、`robe` [96,−62]（晾着的酒红晨衣）、`windmill` [235,−250]、`top` [160,−300]。
断掉的电线：右边三个挂线点 `wire_out` [268,−45]、[260,−129]、[252,−213]，各自往右下方拉出画面，出画处 `wire_end` [320,−1]、[320,−65]、[320,−128]

## 4. 用法示例

```js
ST.tower_ch10 = base('tower_ch10', 'transmission_tower', 320, { music: 'tension', state: {} });
// 跟着仗助往上卷：
G.world.stage.camY = Math.max(-360, Math.min(0, G.world.player.y - 130));
// 宫本的碎纸机开动：
G.world.stage.state.shred = 1;
// 章末把书放上展台：
G.world.stage.state.book = 1;
```
