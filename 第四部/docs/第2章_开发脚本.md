依据：设计文档《JoJo 第四部〈不灭钻石〉像素剧情游戏 · 剧情设计》的「第2章」一节（https://claude.ai/artifact/1wH9fViMTRBgfL8HaeUz1r ），原著 284–293 话。

- 队长：仗助、亿泰；康一从第 3 战起能当。承太郎是酒店门口的 NPC。第 4 战是仗助 ⇄ 康一的 swap 战（亿泰不在场）。

## 3. 战斗

### 第 3 战　锁（`b03_thelock`，康一，home_ch2，不打本人）

康一第一次能操作。开战前出操作提示：「J：回音贴字　K：闪避　L：格挡」。不能换人。

| 项 | 值 |
|---|---|
| 胜利 | 玉美的压力槽 0 → 100（HUD 上方的槽，标题「压力」） |
| 贴字 | J 往前射一个拟声字，四个字轮着来：「咚！」「嗡——」「叮铃铃」「啪！」。贴中 +6；和上一次贴中的是同一个字只 +3。玉美背对康一、两人相距 16 px 以内时，J 直接贴在他耳边 +10。贴中有 10 px 的击退 |
| 内疚 | 每 8 s 玉美说一句让人内疚的话（战斗暂停）：画面出两个回答，左右随机，限时 2.5 s。认错的那句（「……是我不好」这一类）挂一把锁，另一句（「我没有错！」这一类）不挂；时间到没选也挂锁。内疚台词和回答至少各备 6 组，不重复 |
| 锁 | 挂在康一胸口，每把让康一走速 −15%；挂满 3 把被压垮，重来这一段 |
| 门 | 玉美时不时往左边的门跑（喊「伯母！你儿子他——」），碰到门口（x ≤ 40）：门外传来哭声，康一挂一把锁，玉美被推回客厅中间。拟声字的击退可以把他拦住 |
| 玉美的移动 | 不攻击。平时在客厅里绕着康一走，被贴中就捂耳朵 0.6 s；压力过 50 以后跑门更频繁（每 6 s 一次，之前 10 s） |
| 收尾 | 压力满 → 战斗暂停 → 画面暗下来，只剩玉美背过身的剪影（康一·旁白：「他想弄伤自己，让我妈以为是我干的。」，不出现过程）→ 妈妈和姐姐推门冲进来，妈妈胸口的锁变得很大 → 提示「U！」→ 康一 U：金色圆圈，回音飞到妈妈耳边贴一句「相信我！」→ 三把锁一起碎掉 → 玉美投降 |

- 卡住 60 s（压力没涨过 20）：康一·旁白「……他最怕的是吵。绕到他背后贴！」
- 输：被三把锁压垮 → 第三部的“再来一次 / 回到标题”，第二次起出「放水再来」（每 12 s 才说一次内疚的话）。

### 第 4 战　表面（`b04_surface`，仗助 ⇄ 康一，表面 HP 600，×0.9）

**段 A　学校走廊（school_ch2，仗助一个人）**

| 项 | 值 |
|---|---|
| 视线 | 表面面朝仗助、两人在同一行（y 差 ≤ 8）时，表面头上的视线条涨，1 s 满 → 仗助被操纵 2 s：照表面的动作走、出拳（打到康一或空气），玩家按键无效 |
| 破解 | 仗助背对表面，或者换行（y 差 > 8），视线条就往回退 |
| 躲拳 | 表面面朝仗助时，正面打它的 J 都会被它侧身躲开（「哼～」）；从侧面（换行以后）或背后打才中 |
