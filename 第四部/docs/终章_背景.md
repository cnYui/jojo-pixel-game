## 3. 用法示例

```js
ST.emptyhouse_fin = base('emptyhouse_fin', 'empty_house', 480, { music: 'boss', state: { ash: 0, vase: 0 }, obstacles: walls(8, 472, 480) });
G.world.stage.state.ash += 1;          // 撒一次烟灰
G.world.stage.state.vase = 1;          // J3 打碎花瓶
G.world.stage.state.ring = 1;          // 电话响了（抢到话筒以后设回 0）
ST.street_fin = base('street_fin', 'residential_street', 960, { music: 'boss', state: { ambulance: 0 } });
G.world.stage.state.ambulance = 1;     // 救护车到了
G.world.stage.state.siren = 1;
G.world.stage.state.ambulance = 2;     // 回忆里倒车
ST.corner_fin = base('corner_fin', 'morning_corner_rain', 640, { state: { clock: 509 } });   // 8:29
```

## 4. 没画 / 待定

- 设计文档节拍里的“露伴家门口”小卡、尾声那几张一句话的卡片，是过场卡，不在背景里。
