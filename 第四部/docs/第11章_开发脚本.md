## 0. 给实现的人

- 引擎、键位、对话框、名牌、替身卡、VS 卡、地点卡、To Be Continued：全部用现成的。日历地图用序章的 `P4.calendar`（本章往 `P4.CAL` 加一行，红章换成「1999年7月」）。
- 不让玩家操作吉良（设计文档 1.2 第 7 条）：吉良那边的戏是“吉良视角”短过场——冷色罩 + 暗角，玩家不能操作，每段不超过 40 s。
- 早人没有替身：走、K 小跑一步、按住 L 躲（贴着家具 / 邮筒 / 售货机）、E 拿东西、U 用摄像机录。被发现就重来这一小段（第三部的“再来一次 / 放水再来”）。
- 克制（第三部 D10 + 设计文档 4.6）：乙雅三死只给剪影慢慢倒下和掉在地上的图纸筒；“被炸”的人只是一片白光，然后时钟倒转（4.6 第 18 战）；
  早人想寻死那一段只用旁白，不出现过程；箭射中吉良是一道闪光，不画伤口。
- 伤害系数 ×1.2（设计文档 1.2）：本章没有会扣血的正面战斗，只用在战斗 spec 的 `dmgScale` 上。
- 人物 cid：本章画的 `kinoto`（乙雅三）、`cheaptrick`；其他人由第一次出场的那章画（约定第 5 节）。那几章还没合进来，先用 `ph11_*` 临时占位：
  `hayato`→`ph11_hayato`、`kawajiri`→`ph11_kosaku`、`shinobu`→`ph11_shinobu`、`rohan`→`ph11_rohan`、`okuyasu`→`ph11_okuyasu`、`reimi`→`ph11_reimi`、
  `killerq`→`ph11_killerq`、猫草 `straycat`→道具 `ph11_straycat`。剧情里用 `CID('hayato')` 这样取：正式 cid 有图就用正式的，没有才用占位，合并以后不用改代码。
- 队长：插曲、第 18 战只有早人；第 17 战只有露伴（康一跟着走、不能换）。仗助、亿泰、康一只在第 18 战的过场里出现。

### 插曲 爸爸不是爸爸（`b11_spy`，早人，kawajiri_ch11 夜，目标：录到三条证据）

| 项 | 值 |
|---|---|
| 操作 | 方向键走（早人走速 56），K 小跑一步，按住 L 躲（贴着家具：鞋柜 `shoe_rack`、沙发 `sofa`、盆栽 `plant`、冰箱 `fridge`、早人房门 `hayato_door`，14 px 以内），U 录像（站着 2 s，录的时候不能动；躲着也能录），E 没用 |
| 视线 | 爸爸面前一个扇形（长 96 px，上下 ±16），妈妈 72 px。早人在扇形里、没躲着 → 头上的「！」槽涨，0.6 s 满 = 被发现 → 重来这一小段（「被爸爸发现了……」）。放水再来：扇形缩到 70 % |
| 爸爸的巡逻 | 沙发前剪指甲 7 s（面朝左）→ 走去走廊看墙上的全家福 6 s（面朝左）→ 餐桌前练签名 7 s（面朝右）→ 回沙发，一直绕 |

| 证据 | 爸爸做那件事的时候、早人离他 150 px 以内、面朝着他，按 U 录 2 s：①剪下来的指甲收进小瓶子（`nails`）②对着全家福里“自己”的脸看了很久（`photo`）③一遍遍练“川尻浩作”的签名（`sign`）。三条都录到就赢 |
| 提示 | 开场「按住 L：躲在家具后面　U：用摄像机录下证据（离近一点、朝着他）」；60 s 一条都没录到：早人·旁白「躲在他看不到的那一边，等他开始做奇怪的事……」 |

### 第 18 战 败者食尘（早人，不能打）

四次早晨都从 7:00 开始，`corner_ch11` 的钟跟着走（`clock` = 420 + 已过分钟，游戏里 1 s = 1 分钟，过场里跳）。每一次失败只重来这一次早晨。

**循环 1（过场为主）**：7:00 早人在床上醒来，爸爸在餐桌边说出自己的名字（吉良视角不用滤镜，玩家此时操作早人）。
早人出门（`b18_go`：往右走到街口，自由走动，没有输赢）。8:20 露伴从右边走来：「你就是照片上那个孩子？……天堂之门。」
露伴读到早人这一页上的「吉良吉影」→ 白光 → 时钟倒转 → 记住「说出来、被读到，都会被炸」「8:20 露伴老师来街口」。

**循环 2　躲开露伴（`b18_avoid`，corner_ch11）**

| 项 | 值 |
|---|---|
| 胜利 | 撑到 8:25（钟从 8:00 走到 8:25，25 s） |
| 露伴 | 8:05 从右边出来，沿街慢慢往左找（走速 26），视线扇形 90 px；早人在扇形里没躲着 0.5 s → 被叫住 → 失败（「被露伴老师看见了……」） |
| 躲 | 小路口 `alley`、邮筒 `postbox`、カーブミラー `mirror`、售货机 `vending`、民宅 A 门 `gate_a` 前按住 L |
| 8:13 | 仗助、亿泰、康一从小路口走出来去上学（不看早人）→ 记住「8:13 仗助他们从小路口经过」 |
| 收尾 | 8:25，远处爸爸和露伴擦肩而过 → 画面右边一片白光（命运：上一次死掉的人，这一次还是会在同一时刻死）→ 爸爸走过来：「已经发生过的事，会照样发生。」 |

接着仗助他们折回来围住早人追问（「你脸色好差，出什么事了？」）。早人·旁白：「我想到了一个最坏的办法……」（只有旁白，黑场）→ 白光三下 → 时钟倒转 → 记住「谁知道了都会被炸，连我自己也逃不掉」。

**循环 3　告诉他们（过场 + 一次选择，设计文档评论里问过留不留，先留着）**

早人在家门口拦住路过的仗助，出一个选择「怎么告诉他？」：「写在纸上」「给他看录像带」。两个都会被炸（白光）→ 时钟倒转 →
记住「写出来、给他看，也不行」「只有吉良自己说出名字的时候……」。这一段约 40 s，不会输。

**最后一次 段 2　8:13（`b18_corner`，corner_ch11，目标段）**

1. 早人躲在邮筒后面，爸爸走过来。提示「看准时机按 J：猫草的空气弹！」（timing QTE）→ 打中也好、没打中也好，空气弹都被爸爸口袋里的怀表挡住（过场）。

## 7. 原著里没逐格核、这里先这样定的

- 原著的循环是“露伴被炸 → 早人躲开露伴、仗助他们又被炸 → 最后一次”。设计文档写了“三次循环 + 最后一次”，所以把“告诉他们”单独做成第 3 次（文档评论里问过用户要不要留，还没回）；用户说不要就整段跳过，流程不受影响。
- 时刻（8:13、8:20、8:25）是游戏定的，原著没给到分钟。
- 拖延吉良的办法：原著里早人的后手是让仗助他们正好听到吉良说出名字；这里做成“拖时间到 8:13”的选择。
