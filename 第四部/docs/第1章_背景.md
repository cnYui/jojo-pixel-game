## 3. 用法示例

```js
ST.yard_ch1 = base('yard_ch1', 'nijimura_yard', 640, { music: 'tension', state: { gate: 1 }, obstacles: walls(8, 632, 640) });
G.world.stage.state.gate = 0;          // 亿泰把铁门摔上
G.world.stage.state.figure = 1;        // 二楼窗帘后有人
G.world.stage.state.pots_gone = 2;     // 拉过来砸碎了两个；修好一个就减 1
G.world.stage.state.holes = 1;         // 走廊 / 楼梯打完
G.world.stage.state.spark = 1;         // 阁楼插座冒火花
```
