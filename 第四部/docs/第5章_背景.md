依据：设计文档「第5章」一节的场景表（https://claude.ai/artifact/1wH9fViMTRBgfL8HaeUz1r ）。第5章剧情线程开工前没有开发脚本，key 和宽度按文档场景表定，剧情线程照这份用。

## 3. 用法示例

```js
const { base, walls } = G.p4Stage;
ST.rohan_out_ch5 = base('rohan_out_ch5', 'rohan_house', 480, { music: 'tension', state: { window: 0 } });
G.world.stage.state.window = 1;          // 亿泰翻窗进去以后
ST.rohan_in_ch5 = base('rohan_in_ch5', 'rohan_studio', 480, { obstacles: walls(44, 472, 480) });
G.world.stage.state.pages = 1;           // 撒原稿 / 打完
G.world.stage.state.hole = 1;            // 打完：墙上的洞
G.world.stage.state.pan = 1;             // farmhouse：平底锅被拿走
G.world.stage.state.cans = 1;            // farm_out：空罐全打穿
```

## 5. 没画 / 待定

- 发型恩人那段回忆（大雪、车灯）文档写的是剪影过场，没做背景。
- 水渠、牧场、山坡只有白天 + 傍晚罩色，没有夜景。
- 露伴宅的外观是照“白墙洋馆 + 深色屋顶”的印象画的，没逐一对照动画的门窗位置。
