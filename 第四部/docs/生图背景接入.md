原图和元数据继续保存在 `assets/bg/`、`assets/_meta/`。输入是仓库外只读的 `D:/CodeWorkSpace/jojo5_art_out/p4bg/`，不会复制清单、底图或成图进仓库。处理结果写入 `assets/bg_gpt/bg/<背景>/<图层>.png`，构建仍使用原来的 `bg/<背景>/<图层>` 资源键、分包、视差系数和 320×180 分辨率。

在仓库根目录用 PowerShell 运行：

```powershell
$env:PYTHONUTF8='1'
$env:NODE_PATH='D:/CodeWorkSpace/honglou-juan2/node_modules'
python 第四部/tools/bg_gpt_p4.py
python 第四部/tools/build_p4.py --no-font
python 第四部/tools/dev/p4_bg_compare.py
```

`--src <目录>` 可以指定另一份相同结构的只读输入。默认按背景键整组启用：清单中该键的全部任务，包括 near、far、variant，都有可解码的成图才接入。缺图和解码失败会让该组回退，失败详情和保留的开关层记录在 `assets/bg_gpt/_report.json`；失败时返回非零退出码。`--partial` 允许预览已有层，并在报告和对照图中标明 partial；预览后重新运行默认命令并构建，恢复整组门槛。

画布裁切复用生成脚本的居中 band 算法，按成图实际尺寸换算裁切矩形，BOX 缩回原图层尺寸，再做最多 96 色的无抖动量化。near 只在原透明区及一像素边界按洋红阈值抠色，缩小后 alpha 按 128 二值化、约束到原透明轮廓，边界残粉使用原边界色修复，以免删掉正常紫红物件。原图不会覆盖。所有带 `key` 的叠加图（包括整屏开灯变体）保留原图，变体成图仍参与完整性门槛。

重复运行相同输入得到相同 PNG 和报告。每次根据当前输入重新计算全部输出，删除 raw 后重跑会撤下失效组的旧替换图；随后必须重新构建才能更新运行时包。`assets/bg_gpt/` 是流水线专用目录，不要手放素材。构建排除此目录的额外资源键，只在原图有替换时读取替换图，并再次保护 key 叠加层。

报告的 `unplanned` 列出元数据中尚未进入清单的背景，`unrecognized_raw` 列出不匹配任务名的成图；这两类输入不会被自行猜测映射。当前清单尚未覆盖 `national_road` 和 `transmission_tower`，需由后续生图任务清单补齐。

对照图在 `tools/dev/_out/bg_compare/<键>.png`，左旧右新，均按最近邻放大四倍。脚本通过现有 Node Playwright 和生产 `engine/bg.js` 绘制，展示左中右镜头、竖向卷动端点、默认状态、每个开关以及全部开关开启的效果，不需要安装包。
