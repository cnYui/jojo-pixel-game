## morning_corner（住宅区街口，7 月早上）

从左到右：民宅 A（围墙上爬着牵牛花，铁门）→ 电线杆 → 往画面里去的小路（路面写“止まれ”，仗助他们从这里走出来）→ カーブミラー → 街角烟草店 + 红色圆邮筒 → 路边大钟 → 民宅 B + 院子里的树 → 电线杆 + 蓝色售货机 → 公寓。太阳在左边低处，影子往右拖长。

锚点（x, 脚下 y）：clock 钟心 [398, 54]（钟面在 y 43–65，对白框之下）、clock_base [398, 146]、postbox [359, 146]、shop [300, 146]、shop_window [303, 128]、mirror [270, 146]、alley 小路口 [206, 146]、alley_far 小路深处 [206, 116]、gate_a 民宅 A 门 [71, 146]、gate_b 民宅 B 门 [530, 146]、vending [589, 146]、apartment [618, 146]、pole_l [132, 146]、pole_r [572, 146]、walk_x [8, 632]。

开关层：
- `clock`（pick）：值 = 当天的分钟数，7:00 = 420 … 8:30 = 510，每 5 分钟一张，取最接近的。不设时显示 7:00。第 18 战的钟可以直接 `stage.state.clock = 420 + 已过分钟`。
- `dawn`（tint，暖橙 0.10）：刚倒回 7:00 时可以开一下。
- `dark`（tint，深蓝 0.35）：白光前后压暗用。

## street_crossing（商店街到大马路的十字路口，白天）

0–400 铺面：药店くすり、照相馆カメラ DPE（橱窗里一排相片）、花店、杜王銀行转角（ATM）；404–576 横穿的大路，往画面里收向灭点，人行道这一行是斑马线，两边黄色盲道砖；路口两角各一组红绿灯（行人灯 + 横向的车辆灯 + 黄色按钮盒）；580–720 杜王ビル写字楼（玻璃门厅）、路口右角的蓝路牌“杜王グランドホテル →”；720–830 立体停车场的长墙（没有门窗，贴墙走的地方），墙前一个绿色电话亭；830–960 杜王郵便局 + 邮筒。

锚点：pharmacy [50, 146]、camera_shop [148, 146]、camera_window [130, 112]、flower [250, 146]、bank [352, 146]、atm [382, 146]、signal_l [400, 146]、signal_r [580, 146]、crosswalk x 范围 [404, 576]、road_far 大路尽头 [490, 104]、office / office_door [640, 146]、wall 长墙 x 范围 [720, 830]、phone [752, 146]、hotel_sign [637, 146]、post [896, 146]、postbox [923, 146]、exit_x 944、walk_x [8, 952]。

开关层：
- `signal`（pick）：0 或不设 = 行人红灯（车辆绿灯），1 = 行人绿灯（车辆红灯）。
- `pm`（tint，傍晚橙 0.16），和第2章各图同一个 key。
