# 体验版（demo）发布说明

用户 2026-10-10 定：先把**序章 + 第1章**做成体验版发布，后面的章节以后再做。

## 体验版里有什么

- 序章（东京）：牢房自由探索 → 阿布德尔的试探（教学战）→ 学校石阶 / 医务室 → 花京院 → 拔肉芽 → 出发去埃及
- 第1章（香港）：灰塔（飞机）→ 迫降 → 香港街头 → 银色战车 → 波鲁纳雷夫入队
- 打完第1章出「体验版到此结束」，回标题；章节菜单只有这两章。

## 怎么打包

```powershell
# 在游戏目录
python -B tools\dev\make_demo.py
```

输出到 `游戏素材\JoJo\发布\JoJo星尘斗士_体验版_<日期-时间>\` 和同名 `.zip`（解压出来是一个文件夹，玩家双击里面的 `index.html`）。
已存在就加序号，不覆盖旧包。

打包做的事：只拷运行要用的文件（`index.html`、`main.js`、`engine\`、`story\`、`data\`、`assets\video\`）；`index.html` 里写 `window.JOJO_DEMO = { last: 1 }`；写一份给玩家看的 `说明.txt`；**不拷 `data\music\title_song.js`**。

## 版权

- **标题曲《STAND PROUD》不随发布包分发**：商业歌曲，用户提供时就说好只在本机自己玩。体验版的标题曲自动换成原工程自带的 `title`（像素动画原工程合成的配乐）。
- 片头 `op` / 序幕 `coffin` 两段动画是原工程的像素场景重渲的，配乐和音效都是原工程合成的，可以带。
- 标题画面和 `说明.txt` 写了“同人作品，免费，非商业；角色与故事版权归原作者”。
