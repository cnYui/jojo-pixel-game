# 第四部：天堂之门（岸边露伴的替身）按官方形象重画（2026-11-24）

## 起因

用户说露伴的天堂之门形象“完全不对”，给了一张官方形象图并让联网查：银白色礼服、金色滚边和袖口、金色镂空格栅的高礼帽、绿眼睛、橙色领结和鞋。游戏里的旧画法是米白披风 + 宽檐草帽的小人（`p4_chars_ch5.py` 的 `hd_frame`），宣传片的露伴人物卡上也是它。

联网查到的设定（萌娘百科、JoJo Wiki）：白色配黄色线条，外表是穿礼服、戴高帽的小孩，形象来自露伴漫画《红黑少年》的主角，帽子在漫画里是平顶、OVA 里改成圆顶。绿眼睛、格栅帽身、橙色领结这些细节页面里没写，以用户给的图为准。

## 做了什么

- 新脚本 `第四部/tools/art/p4_hd.py`：字符格子 + 圆头笔画逐像素画，全尺寸格 48×48、脚点 (20, 45)，之后和别的人物一样用 `shrink` 缩成 5/8（游戏里 31×31）。
  - 帽子：镂空的金色格栅帽身（4 条竖条、2 道横条，窗里银白）、金色帽带、银白宽檐带金边；脸银白、绿眼、眼下和脸颊的金线、鼻子；礼服银白 + 正中金色拉链线和三粒金扣、领口和下摆金边；橙色领结、金色袖口、橙色鞋。
  - 姿势：idle（4 帧上下浮动）、wind / punch / punch2（出拳）、upper（上勾）、rush / rush2（冲刺 + 速度线）、block、hurt（闭眼张嘴）、write（伸手 + 一页纸，两帧翻动）。动作名和帧数跟旧版一致（引擎按这些播），amap 没动。
  - 说话头像 32×32：帽子 + 脸 + 领结（`portrait()`）。
- `p4_chars_ch5.py`：`build_heavensdoor()` 改用 `p4_hd`；新增命令行 `python 第四部/tools/art/p4_chars_ch5.py heavensdoor`，只重出天堂之门并只替换 `_meta/chars_ch5.json` 里 `chars.heavensdoor` 一条。**不要不带参数跑这个脚本**：重画之后露伴已经是新人物，整个 `main()` 会把他覆盖回旧版。旧的 `hd_frame` 留着备查。
- 宣传片的人物卡脚本（仓库外 `jojo4_redraw_out/promo_1124/cards.py`）：天堂之门改用全尺寸图集、放大 11 倍（其他替身仍用游戏里缩小版放 18 倍）。

## 验证

- `PYTHONUTF8=1 python 第四部/tools/build_p4.py --no-font`：图片 1450、角色 113、背景 70，无报错。
- 自动通关（快进）：`p4_play.js --chapter ch5` 通过（标记 31、报错 0、拳声漏停 0），`--chapter ch11` 通过（标记 35、报错 0）。第 5 章第 7 战（天堂之门）整场世界层罩黑，这个替身在战斗里几乎看不到，主要出现在说话头像、替身卡和宣传片人物卡上。
- 对比图（项目资料库）：官方图 + 新画整身 + 各姿势、露伴人物卡改前改后。
