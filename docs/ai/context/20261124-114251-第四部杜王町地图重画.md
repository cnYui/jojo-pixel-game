# 第四部：杜王町地图（morioh_map）重画（2026-11-24）

## 起因

用户截了各章开头日历地图的图，说要重新画：旧图是旧纸上几笔线、房子只是色块。这张图在序章到终章的日历节拍都会出现，图钉落在上面。

## 做了什么

- 新脚本 `第四部/tools/art2/bg_map.py`（`python 第四部/tools/art2/bg_map.py <核对图目录> --save`）：全用代码逐像素画，写 `assets/bg/morioh_map/map.png` 和 `_meta/bg.json` 里这张图的锚点、图层。
  - 地形：高度图 + 西北光晕渲，山上一颗颗树冠；北坡一行行葡萄园（“葡萄丘”）；西边水田和用水路、西北牧场（仓库、筒仓、牛）。
  - 水：海按离岸距离分六档深浅、浪纹、岸边白浪、沙滩和海岬岩岸；河有堤岸、堤上一排树、河边公园和池塘。
  - 铁路：浅色道床、枕木、两条轨，过河是铁桥，西头钻进山里的隧道口；车站北侧月台和雨棚、天桥、停着的电车，站前环岛、公交、出租车。
  - 路网：国道和杜王大道（黄色路面 + 白色虚线中线）、干道、住宅区小路、幽灵小路那条窄巷、桥、斑马线、路上的车。
  - 房子：每栋屋顶分坡面明暗（两坡 / 四坡 / 瓦顶 / 平顶带屋顶设备 / 拱顶），南墙有窗和门，往东南落影子；成片住宅按街区一排排紧挨着放，空当铺小院子、种树。
  - 地标对准图钉：葡萄丘高中（操场、跑道、樱花、泳池）、葡萄丘中学（棒球场）、杜王站（红屋顶）、银行（列柱 + 葡萄招牌）、灰姑娘美容院、裁缝店、意大利餐厅、宫本 / 吉良旧宅 / 川尻 / 东方家 / 康一家、超市和停车场、虹村家（荒院 + 铁栅栏 + 破窗）、露伴宅、海岬的海边别墅和灯塔、港口（三道栈桥、集装箱、吊车、渔船、SPW 的船、两道防波堤和红白灯塔）、送电铁塔和电线、神社鸟居、天使岩、医院、杜王大酒店、图书馆。
  - 图框改成黑白相间的经纬格带，右上角给「M县S市 杜王町」那行字做了一块挂在图框上的地名牌，东南海面放指北针，左下比例尺。
  - 海面和河面加了一层一闪一闪的反光（背景图层 `stars`，52 个点，避开红章和指北针）。
- 红章固定盖在 x 250–284、y 118–145（`p4_common.js` 写死），这块留成空海面。
- 锚点（元数据 `morioh_map.anchors`）：`sea`（杜王港）挪到主栈桥 (281,90)；新加 `villa` (288,46)；`c11_rohan` / `c11_alley` 和第 5、6 章的露伴宅、幽灵小路统一成同一处；`c11_kawajiri` 给了川尻家自己的房子 (112,146)；其余各章在剧情里写的默认值照抄进来。
- `p4_ch3.js`：「海边别墅」图钉原来写死 [266,136]，旧图上就落在海里、还被红章盖住；改成先读锚点 `villa`，没有再用旧坐标。
- 旧的画法 `tools/art/p4_bg.py` 的 `morioh_map()` 没删，加了注释：别再用它出图。
- 新工具 `第四部/tools/dev/p4_calview.js`：在真游戏里放日历动画按时间截图，`--pins` 把各章全部图钉一起摆上去核对。
