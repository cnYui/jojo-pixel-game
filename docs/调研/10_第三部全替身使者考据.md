## 0. 口径与标记

- **顺序**以漫画话数为准（JoJo Wiki 的篇章表：花京院 118–121、灰塔 122–123、银色战车 124–126、暗蓝之月 127–129、力量 130–132、恶魔 133–135、黄色节制 136–139、皇帝与倒吊人 140–145、女帝 146–149、命运之轮 150–153、正义 154–159、恋人 160–165、太阳 166–167、死神13 168–173、审判 174–178、女教皇 179–182、愚者与盖布神 183–188、克努姆与托特 189–192、阿努比斯 193–198、巴斯特 199–204、塞特 205–210、赌徒达比 211–216、荷尔·荷斯与波因哥 217–221、佩特夏普 222–226、玩家达比 227–237、瓦尼拉·艾斯 238–246、DIO 的世界 247–265）。
- **确定度**：正文里不标 = 这次查证过（JoJo Wiki 篇章 / 角色页、英文维基分集表），或者本地分镜里已经有、和原著一致；**（≈）** = 大意确定，但细节（地名、台词措辞、谁动的手）没有逐字核对；**（待核）** = 记忆里有、没查到来源，实现前请再查一次。
- **台词 / 梗**只写中文圈常用的短说法，不照抄原文。
- **精灵状态**：「有」= 角色图集里有，给 id 和动作帧数；「仅待机」= 只有 idle（1–2 帧），做 Boss 要补攻击 / 受击 / 倒地；「无（新画）」= 要按同画风重画。具体缺哪些动作见第 6 节。
- **数值约定**（只是建议，给实现定个起点）：
  - 时间用 60 Hz 帧（f）。
  - 距离用 JoJo 原片基础画布 **320×180** 的像素（px）。如果最后用银魂那样的 384×216 画布，乘 1.2。
  - 伤害以「玩家普通拳一下 = 10」为基准。Boss HP 前期 600–900，中期 900–1400，九荣神 1200–1800，瓦尼拉·艾斯 2000，DIO 每段 1500–2200。

## 3. 通用战斗基线（各 Boss 机制都按这个写）

用户定的键位：J 替身出拳（三连，连按 = 欧拉连打）、K 闪避（残影 + 短暂无敌，**不做跳跃**）、L 替身格挡、U 替身必杀（血条下的能量满了才能放）。

| J 三连 | 第 1、2 下前摇 6f，伤害各 10；第 3 下前摇 9f，伤害 18，击退 24 px | 第 3 下按角色换成特色招（花京院 = 触须网，阿布德尔 = 火球，波鲁纳雷夫 = 突刺） |

## 4. 逐战详解

### 第一部 · 日本 → 香港

#### 序1 · 拘留室：阿布德尔的试探（教学战）

- **地点**：1987 年东京，警署拘留室。现成背景 `bg.jail_cell` + 前景 `bg.jail_bars`（bend 参数 0→1 是铁栏被扳弯的过程）。
- **敌方**：穆罕默德·阿布德尔 / 红色魔术师。是友方故意试探，不是 DIO 的刺客。
- **能力**：火焰、十字火焰风暴、红色束缚（火绳）。
- **我方**：承太郎。
- **怎么赢的**：承太郎以为自己被恶灵附身，不肯出牢房；阿布德尔放火逼他。白金之星挡住火焰、扳弯铁栏，承太郎自己走了出来。乔瑟夫说明：那不是恶灵，叫「替身」。（分镜 s02 已有）
- **台词 / 梗**：「我被恶灵附身了，别管我」「呀嘞呀嘞daze」；承太郎用替身在牢里拿漫画、收音机。
- **Boss 机制**：
  - 阶段 1：火球从栏外直线飞来（预警 30f 火光），教 K 闪避和 L 格挡。被打中掉 8，HP 不会低于 1（教学战不死）。
  - 阶段 2：红色束缚——地面出现火绳圈，预警 40f 红圈，教精准格挡。
  - 收尾：能量自动充满，提示按 U，白金之星扳弯铁栏（直接驱动 `bg.jail_bars` 的 bend）。
- **操作角色**：承太郎（锁定）。
- **素材**：全有：`avdol`（cast 2f）、`magred`（idle、cast）、`starplat`（block）、`fx.fire_ankh`、音效 `fire_burst` / `fire`。

> **剧情节点**：乔瑟夫用隐者之紫砸相机念写出 DIO 的背影（s03），DIO 夺走了乔纳森的身体。承太郎脖子后面的星形胎记。

#### 序2 · 校门：花京院（被 DIO 的肉芽控制）

- **地点**：东京，学校（原著是校园和医务室，像素片用 `bg.school_gate`）。
- **敌方**：花京院典明 / 绿色法皇。
- **能力**：远程操纵的触须（可以钻进别人身体里操纵人，原著操纵了校医）；绿宝石水花（宝石弹幕）。
- **我方**：承太郎（乔瑟夫最后用波纹）。
- **怎么赢的**：白金之星硬吃水花，抓住触须扯回来，欧拉把花京院打倒。之后承太郎用白金之星的精密动作把肉芽从他额头拔出来——肉芽的触手往承太郎手里钻也不松手，乔瑟夫用波纹烧掉肉芽。（分镜 s04 已有）
- **台词 / 梗**：「绿宝石水花！」；「为什么……要救我？」「……谁知道呢。」
- **Boss 机制**：
  - 远程型：花京院站在后排，绿色法皇用触须线连着他（`fx.tendrils`），本体每 3 s 换一次位置。
  - 绿宝石水花：12 发扇形弹幕（`fx.emerald_splash` + 音效 `emerald`），预警 24f 绿光；L 能全挡，但被推后 16 px。
  - 触须陷阱：地面出现绿线，踩上去定身 40f。
  - 诀窍：靠近绿色法皇时精准格挡它的触须攻击 = 抓住触须 → 扯回 QTE（60f 内按 J ≥ 10 下）把花京院拉到面前 → 欧拉。
  - 收尾小游戏「拔肉芽」：方向键把准星保持在额头肉芽中心 3 s，抖动越来越大（触手往手里钻，屏幕边缘泛红），偏出去就重来；成功后乔瑟夫波纹（`fx.hamon`、音效 `hamon`）。
- **操作角色**：承太郎（锁定）。
- **素材**：全有：`kakyoin`（possessed、cast、hurt、down）、`hiero`、`s04_*`（花京院坐地、昏迷脸、被附身头像、白金之星的手）、`prop.fleshbud`（3f）。

> **剧情节点**：荷莉的替身觉醒，荆棘藤蔓长满后背，病倒——撑不过 50 天（s05 有大字「50」倒计时）。SPW 财团派医生照顾荷莉。DIO 在埃及：原著是从念写照片里的苍蝇（只有阿斯旺一带才有的品种）判断出来的（≈）。承太郎「我去把 DIO 揍扁」，花京院同行，目标埃及。

#### 第 1 战 · 灰塔（飞往香港的客机）

- **地点**：日本飞往开罗的客机上，最后迫降在香港外海。
- **敌方**：格雷·弗莱（一个老头）/ 灰塔（锹形虫样子的小替身）。
- **能力**：极小、极快（子弹都打不中），嘴里伸出长针「塔针」刺人、拔舌头，射程很远。
- **我方**：花京院（主），承太郎先上来打不中。
- **怎么赢的**：白金之星抓不住它；花京院用绿色法皇的触须布网，加近距离一齐射出的绿宝石水花打中它。驾驶员已经被杀，乔瑟夫接过操纵杆迫降香港外海。
- **台词 / 梗**：乔瑟夫「这是我人生第三次坠机了」（s06 已用）；承太郎「以后再也不跟你坐同一架飞机」（大意，≈）。
- **Boss 机制**：
  - 场地：机舱过道（`bg.plane_cabin`），座椅一排排当掩体。
  - 灰塔：碰撞箱 6×6 px，速度 240 px/s，追的是乘客 NPC，不是玩家。每 4 s 挑一个乘客俯冲，8 名乘客全被刺倒 = 失败。
  - 承太郎（可选先上 10 s）：它在拳头出手前 6f 就闪开，拳头基本打不中——用来教「这不是承太郎的场子」。
  - 花京院：J 第 3 下换成「触须网」，在前方 64 px 铺 8 根线、持续 90f，灰塔碰到被缠 30f；U = 绿宝石水花（12 发全屏追踪）。
  - 诀窍：灰塔没被缠住时伤害 ×0；先用触须网缠住，再放水花必中。灰塔 HP 300。
  - 收尾：水花打碎它（`fx.shatter`），格雷·弗莱现形倒下 → 驾驶舱 QTE：乔瑟夫拉操纵杆（现成镜头 `s06_plane.py` 的 `shot_cockpit` / `shot_dive` / `shot_splash`）→ 坠海。
- **操作角色**：花京院（锁定）。
- **素材**：`towergray`（fly 2f）有；格雷·弗莱无（idle、hurt、down）；乘客 NPC 可以拿 `s09_man` / `s09_woman` 调色；`s06_pilot_ko`、`s06_cap`、`prop.plane` / `prop.plane_crash` 有。

> **剧情节点**：乔瑟夫的「交通工具厄运」第一次发作（坠机计数器可以做成贯穿全篇的小梗，见第 5 节）。

#### 第 2 战 · 银色战车（香港·虎豹别墅）

- **地点**：香港，虎豹别墅风格的花园（`bg.hk_garden`），前面是霓虹夜街（`bg.hongkong_night`）。
- **敌方**：让·皮埃尔·波鲁纳雷夫（被肉芽控制）/ 银色战车。
- **能力**：剑术极快极准，能把空中的硬币一剑串起；能劈开火焰；吸收火焰后铠甲脱落，速度暴涨、分出多个残影。
- **我方**：阿布德尔。
- **怎么赢的**：波鲁纳雷夫切开火焰占上风，拍手让银色战车脱甲，阿布德尔一度被压着打；阿布德尔放出「十字火焰风暴 Special」——好几个安卡形火焰，其中一道直接从地底下冒出来，打中波鲁纳雷夫。阿布德尔饶他一命，承太郎拔掉肉芽，波鲁纳雷夫入队。
- **台词 / 梗**：「YES I AM!」（阿布德尔竖手指，s07 已用）；「我在找一个有两只右手的男人……他杀了我妹妹。」
- **Boss 机制**：
  - 波鲁纳雷夫是剑客：近距离三连刺，每刺前摇 6f，判定 40×6 px；只能 K 或精准格挡，普通格挡会被刺穿（还是吃 30%）。
  - 斩火：阿布德尔的火从正面打过去、距离 ≤ 80 px 时，70% 被剑切开（火焰碎块可以抄 `s07_polnareff.py` 的 `fire_chunks`）。
  - 阿布德尔专属：U = 十字火焰风暴（`fx.fire_ankh`）；按住 L 再按 J = 地火：在 Boss 脚下的地缝里延迟 40f 冒出火柱。这就是原著诀窍——从地下来的火切不到。
  - 阶段 2（HP < 50%）：脱甲。银色战车掉甲，速度 ×1.8，出现 2 个残影（`fx.afterimage`）。残影也会刺，但只有真身吃伤害；区分办法：只有真身脚下有影子（`fx.shadow`）。
  - 收尾：十字火焰风暴 Special 命中 → 烤焦（`s07_pol_char`）→ 拔肉芽小游戏（同序2，难度降低）。
- **操作角色**：阿布德尔（锁定）。
- **素材**：`polnareff`（fight 2f 等）、`chariot`（idle、thrust 3f）、`s07_*`（被烤焦、弹硬币、跪地）有；脱甲版银色战车无（idle、thrust 各 2–3f）。

> **剧情节点**：波鲁纳雷夫入队，说出要找杀害妹妹雪莉的「双右手的男人」——第 7 战的伏笔。

### 第二部 · 海上 → 新加坡 → 印度

#### 第 3 战 · 暗蓝之月（去新加坡的客船·海中）

- **地点**：香港开往新加坡的客船，然后是海里（`bg.underwater`）。
- **敌方**：冒牌坦尼尔船长 / 暗蓝之月（鱼人）。
- **能力**：水中替身。鳞片散布在水里挡住支援、再打过来；造漩涡困人；在对手身上长藤壶，又割又吸力气。
- **我方**：承太郎。
- **怎么赢的**：真船长是 SPW 审核过的，阿布德尔不信他有问题。承太郎当众扯谎「抽烟以后鼻子上的血管会浮出来」，大家都去摸鼻子，船长也摸了——这个谎套出了冒牌货。被拖下水后，白金之星第一次用「星之指」（手指伸长）戳破藤壶、刺穿它的手和眼睛。偷渡少女安妮被假船长挟持，被白金之星救下扔给绿色法皇接住。船上早就装了炸弹，众人坐救生艇漂流。
- **台词 / 梗**：「鼻子上的血管」骗局；安妮跳海躲鲨鱼，白金之星一拳打飞鲨鱼。
- **Boss 机制**：
  - 场地：甲板（短）→ 水下（`bg.underwater` + `fx.underwater_wobble` + `fx.caustic_light`）。
  - 开场调查：自由走动时和船员、船长对话，最后选项「揭穿船长」（选对了直接开战，选错扣一点氧气时间当惩罚）。
  - 水下规则：氧气槽 20 s（每秒 −5%），K 变成划水冲刺，承太郎移动 ×0.6，Boss 移动 ×1.4。
  - 鳞片：3 发扇形（4×4 px），可以格挡。
  - 藤壶：被打中身上长 1 个（最多 5 个），每个让移动 −10%、每秒 −1 HP；按住 L 2 s 刮掉 1 个。

#### 第 28 战 · 世界：DIO（终章多段）

- **地点**：DIO 宅邸大楼梯（`bg.mansion_stairs`）→ 开罗夜街（`bg.cairo_street`）→ 开罗屋顶（`bg.cairo_rooftops`，钟楼、水塔）→ 开罗街道（黎明）。
- **敌方**：DIO / 世界。
- **能力**：近身力量和速度都和白金之星同级（同为近距离力量型）；「咋瓦鲁多」时间停止（起初约 5 秒，吸了乔瑟夫的血后变成 7 秒、9 秒）；时停中摆飞刀；吸血鬼的再生、吸血、怪力；压路机。
- **我方**：波鲁纳雷夫（楼梯）、花京院（屋顶，战死）、乔瑟夫（被杀）、承太郎（决战）；决战中波鲁纳雷夫赶来插了一剑。
- **原著经过**：
  - 楼梯：DIO 一次次把波鲁纳雷夫「送回」楼下——「我刚才明明在上楼梯，回过神来却在下楼」（s14 现成）。承太郎、乔瑟夫、花京院破墙赶到，DIO 躲进宅子里避开阳光。
  - 追车：DIO 拔掉上议员威尔逊·菲利普斯的门牙逼他开车，一路撞人；乔瑟夫和花京院开车追，车被撞毁，两人上了屋顶。
  - 屋顶：花京院布下半径 20 米的绿宝石水花触须网；DIO 时停，把网全部切断，一拳贯穿花京院的腹部，把他打进水塔。花京院临死前看到钟楼，明白了 DIO 的能力是「时间」，最后一发绿宝石水花打碎钟面，把讯息留给乔瑟夫（s15 现成）。
  - 乔瑟夫：用隐者之紫捆住 DIO，被挣脱；时停中被瓦砾打下屋顶，时间恢复的瞬间被飞刀刺中脖子；DIO 后来吸干他的血，「最高哒！」（s16 现成）。
  - 承太郎：两替身正面对打不相上下。DIO 时停想收拾承太郎，却发现承太郎的手指动了一下——承太郎能在停止的时间里动（起初只有约 1 秒）。DIO 时停摆飞刀阵，承太郎身中数刀，靠塞在衣服里的杂志挡住了要害。承太郎装死，还让白金之星停掉自己的心跳骗过 DIO；DIO 拿路牌要砍头时，波鲁纳雷夫一剑刺进 DIO 的头。DIO 吸了乔瑟夫的血后时停延长到 9 秒，扔下压路机（「压路机哒！」）；承太郎在压路机下面撑住，在 DIO 的时停里用自己的时停反超，踢断 DIO 的腿；最后两替身对踢，世界的腿裂开，DIO 的身体从中间裂开（s17、s18 现成）。
  - 之后：SPW 回收遗体。承太郎让白金之星重新启动乔瑟夫的心脏，把 DIO 的血输回他体内，乔瑟夫复活，还装成 DIO 开玩笑（s19 现成）。日出，DIO 的遗体化灰。
- **台词 / 梗**（STYLE.md 第 6 节已有）：「咋瓦鲁多！」「木大木大木大！」「压路机哒！」「最高哒——！」「你以为是……吗？是我 DIO 哒！」「你的失败只有一个原因……就是你惹我生气了」。
- **Boss 机制（每段算一场独立战斗，输了只重来这一段）**：
  - **段 A 楼梯（操作波鲁纳雷夫，必败演示）**：按上爬楼梯，进度到 70% 时「咋瓦鲁多」（不预警），画面跳回楼下（s14 现成）。重复两次后剧情推进。作用：让玩家第一次体验时停。
  - **段 B 屋顶（操作花京院，必败 + 临死一击）**：
    - 布网：J 在屋顶 8 个节点放触须（`fx.tendrils` + `s15_kakyoin_last.py` 的 `draw_web` / `_seg_grow` 现成），DIO 在空中逼近，30 s 内布完。
    - 网满后 DIO 一碰就触发全方位水花——然后「咋瓦鲁多」（黄色时停：`fx.timestop` tint=yellow）→ 网被切断（`_seg_cut`）→ 强制中拳。
    - 临死 QTE：瞄准钟楼（`prop.clocktower`，夜景版 `s15_clock_n` 有 3 个状态：4:00 / 指针跳变 / 表盘碎裂）射出最后一发水花。只有一次机会，失败可以重试这一下。
  - **段 C 乔瑟夫（短战或并入过场）**：隐者之紫缠住 DIO（连按 J）→ 一定会被挣脱 → 时停飞刀（强制）。
  - **段 D 承太郎决战（三阶段，Boss HP 按 100% 计）**：
    - D1（100% → 60%）正面拳拼：世界对白金之星（`theworld` punch / rush 对 `starplat` punch / rush）。「对冲」：双方同时连打时 3 s 内按 J ≥ 20 下赢下对冲，DIO 硬直 60f。
      - 咋瓦鲁多（核心机制）：预警 = DIO 喊「THE WORLD」（头像 + 黄光脉冲 45f，同时播 `timestop` 音效前半段的反向镲上升）。时停在游戏里压缩成 2 s：期间玩家不能动，DIO 走过来打或摆刀。对策：时停发动的瞬间按住 L（「提前防御」）→ 受伤 ×0.3；或者在 45f 预警里 K 闪离 DIO 的接近路线（刀在时停结束时才飞出，恢复的那一帧还能再 K 一次）。
      - 成长：第 2 次时停时出现「手指动了」QTE——停止的世界里连按 J 15 次 → 承太郎在时停中能动 0.5 s，打 DIO 一拳，DIO 震惊（`s18_final2_dio_shock`）。
    - D2（60% → 30%）飞刀阵 + 装死：
      - 飞刀阵：DIO 时停后在玩家周围 360° 摆 16 把刀（`fx.knives(fr, items, t, frozen=True)` + `s17_final1.py` 的 `_mk_knives` 现成），时间恢复时一齐飞来。对策：用时停中那 0.5 s 转身打掉一面的刀（欧拉弹刀，`_knife_sparks`），其余硬吃——「杂志」buff 让前 3 把刀免伤。
      - 装死：HP 低于 35% 时提示「停止心跳」，按住 L+K 3 s 进入装死（心电图平线 UI）；DIO 走近，拿路牌准备砍头 → 波鲁纳雷夫插一剑（剧情）→ 白金之星反击窗口 90f，伤害 ×2。
      - 吸血：DIO 逃去吸乔瑟夫的血（s16 过场）→「最高哒」→ 全面强化：时停在游戏里变 3 s（对应原著 9 秒），攻击 +30%。
    - D3（30% → 0）压路机 + 最终对冲：
      - DIO 从天而降砸下压路机（预警：天空阴影 60f +「压路机哒！」；`prop.roadroller` 三个状态：干净 / 破损 / 裂纹发光），时停中躲不开。被压住后 QTE：3 s 内按 J ≥ 45 下把压路机顶起来 → 承太郎的时停「白金之星·世界」（蓝色 `fx.timestop_world`）→ 绕到 DIO 背后踢断他的腿（自动演出）。
      - 最终对冲：欧拉对木大连打拼 5 s → 赢 → 世界裂开（`theworld.crack` 2f）→ DIO 崩碎（`dio.crumble` 4f）→「你的失败只有一个原因」。
  - 收尾：黎明（s19）→ 乔瑟夫复活、荷莉苏醒 → 机场告别（s20）。
- **操作角色**：段 A 波鲁纳雷夫；段 B 花京院；段 C 乔瑟夫；段 D 承太郎（全部锁定）。
- **素材**：这是素材最全的一战：`dio`（11 个动作）、`theworld`（7 个动作）、`prop.knife`、`prop.roadroller`、`prop.clocktower`、`prop.watertower`、`s14`–`s19` 的场景专用精灵、`fx.timestop` / `time_resume` / `timestop_world` / `knives` 全有。要补：DIO 本人的近身攻击帧（可以先让世界代打）；威尔逊·菲利普斯无（可选）。
