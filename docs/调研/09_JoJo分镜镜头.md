## 0. 结论速览

1. **原片的一切画面 = 纯时间函数**：每个场景 `render(fr)` 只看 `fr.t`，特效粒子全部由 `hash01(seed, i, …)` 解析算出、不带状态（`core.py:4-5`、`fx.py:3-17`）。所以任何一个镜头都能**逐行移植成 JS 的 `draw(t)`**，也能**直接用原工程渲染成视频**，两条路都通。
2. **两层画面**：像素层 320×180（`fr.img`，角色 + 背景 + 全部 fx）和 UI 层 640×360（`fr.ui`，对白框、替身卡、名牌、拟声字、ゴゴゴ）。镜头推拉 / 抖动**只作用于像素层**，UI 文字永远在 640×360 网格上清晰（`Frame.compose`，`core.py:262-298`）。游戏要照这个分层做。
3. 原片“炫”的东西几乎都在 `engine\fx.py` 一个文件里，有统一接口：替身召唤 `stand_summon`、欧拉连打 `rush`、时停 `timestop / time_resume / timestop_world`、冲击帧 `impact_frame`、打击火花 `hit_spark`、冲击环 `shockwave`、集中线 `speedlines`、迷幻底图 `menace_bg`、放射底图 `radial_burst_bg`、残影 `afterimage`、碎裂 `shatter` …… 这些**必须移植成 JS 实时画**（战斗里要随玩家操作触发，视频做不到）。
4. 卡片类（替身卡、名牌、地点卡、大标题、拟声字、ゴゴゴ、对白框）都在 `engine\text.py`，参数很少，JS 照抄即可；VS 卡在 `s10_montage1.py:336-359`，世界地图过场是 `bg.world_map` + `bg.draw_route`（`bg_asia.py:868-1135`）。
5. **建议分工**：
   - **视频（直接用原工程渲染）**：开场 s00（14.0 s）+ s01（10.0 s）必做；片尾 s20（17.0 s）建议做；剧情里不可操作、几乎全是自绘、改不动台词也无所谓的高潮（s13 阿布德尔被抹消、s15 花京院之死、s16 乔瑟夫被吸血、s18 终结一拳→DIO 化灰→日出）可选做成“插片”。
   - **JS 实时**：所有战斗特效、所有替身召唤、所有 VS 卡 / 替身卡 / 名牌、世界地图、必杀（U）特写切入、时停（DIO 战的机制、承太郎后期的“白金之星·世界”）、ORA vs MUDA 对拼（建议做成连按 J 的对拼小玩法）。原片里没出现的那十几个替身使者也只能靠这套 JS“镜头语法”做。
6. **开场动画实测**：s00+s01 共 576 帧，用本文附录 A 的包装脚本（不往 `源码\` 写任何东西）渲成 1280×720：画面 9.4 s、混音 7.0 s、连 webm 一共 **32.7 s**；产物 mp4（H.264 + AAC）**12.96 MB**、webm（VP9 + Opus）**11.61 MB**。各场景单帧 5–12 ms。**不要直接跑 `tools\render.py`**：它把分段、临时音视频、`timeline.txt` 写进 `源码\out\`（`common.py:9`、`render.py:27,205-232`）。
7. 风险 / 待定见第 7 节，最大的两个：s00 的剪辑点是踩原片芯片乐 `title`（143.55 bpm）的节拍，换成 STAND PROUD 会错拍；视频里中文台词是烧死的。

## 1. 原工程的渲染模型（移植前必须懂）

### 1.1 画布与合成顺序

| 项 | 值 | 位置 |
|---|---|---|
| 像素层 | `W, H = 320, 180`，`fr.img` RGBA | `core.py:13`，`Frame.__init__` 202-214 |
| UI 层 | `UI = 2`，640×360，`fr.ui` 透明底，`ud.fontmode = '1'`（文字无抗锯齿） | `core.py:14-15, 205-208` |
| 成片 | 640×360 合成图再 ×3 最近邻 → 1920×1080，24 fps | `core.py:16-17`，`render.py:29`（`scale=…:flags=neighbor`） |
| 合成顺序 | ① `flash`：像素层整体混向某色 → ② `zoom` + `shake`：在像素层裁一个框（z≥1 时夹在画布内，抖动平移框，越界补黑）再最近邻放到 640×360 → ③ 叠 UI 层 → ④ `fade`（平滑）→ ⑤ `dither_fade`（Bayer 抖动，cell=2） | `core.py:262-298` |
| 场景渐入渐出 | `FADE_IN / FADE_OUT`（默认 0.3 s）在 `common.render_frame` 里统一加 Bayer 抖动溶解到黑 | `common.py:33-46` |

要点：
- 推镜（`fr.zoom(z,cx,cy)`）是“裁框 + 最近邻放大”，**非整数倍 zoom（如 2.3）像素块会不等宽**——原片就是这样，游戏照做或限定 0.5 步进都行。
- 黑边（letterbox）大多画在 **UI 层**，避免被 zoom 裁掉：s04 `_ui_letterbox`（301-305）、s13 `_bars`（301-306）、s15/s17 `_ui_letterbox`、s18 `ui_bars`（351-355）。`core.letterbox` 画在像素层（只有 s00 片尾用）。
- 冲击帧、时停、迷幻底图这些“全屏滤镜”**只处理像素层**，文字不受影响（`fx.py:13-15` 的约定）。

### 1.2 摄像机

- 原始接口：`fr.zoom(z, cx, cy)`（`core.py:231-234`）、`fr.shake(amp, seed=0, freq=30)`（223-229，抖动值 30 Hz 换一次，`round((hash01(k,seed,1)*2-1)*amp)`）。
- 每个场景都自己包一层防黑边：
  - s02 `cam()`（144-155）：抖动边距 `m = ceil(shake)+1`，zoom 至少 `1+(2m+2)/H`，中心夹在 `[W/2z+m, W-W/2z-m]`。
  - s10 `camera()`（246-263）：**抖动改成移动 zoom 中心**；z≤1 又要抖时自动给 `H/(H-2m)` 的微 zoom ——这个写法最干净，**游戏建议照它**。
  - s04 / s15 `_cam()`（s04:284-293、s15:329-345）额外**返回 base→UI 的坐标映射函数**，用来把 UI 文字钉在像素层物体上（s15 的 ゴゴゴ 跟着 DIO 走，`s15:934-936`）。
  - s17 `_cam()`（344-355）：取景框离画布边留 7 px。

### 1.3 时间与“手绘感”

- 场景帧数 `round(DURATION*24)`（`common.py:29-30`）。
- 冲击帧都写成 `T <= t < T + 1/24`（恰好 1 帧）；关键打击点用 `fq()` 对齐到帧格（`s07:25-27`、`s18:28-30`：`math.ceil(t*FPS-1e-6)/FPS`）。
- 很多效果故意 12 fps 步进：`speedlines(fps=12)`、`aura_flame(fps=12)`、`menace_bg(fps=12)`、`void_sphere`（`floor(t*12)`）；`stepped()`（`core.py:151-153`）。移植到 60 Hz 时**保留这个步进**，不然会“太顺滑、不像原片”。

### 1.4 声音（镜头都踩拍）

- 画面里 `fr.sfx(name, at, **kw)` 登记事件（`core.py:217-220`），模块级 `SFX = [(at, name, kw)]` 静态列表，`MUSIC` 可是字符串或 `[(t, key), …]` 分段（`scenes/__init__.py:1-9`）。
- 混音 `render.build_audio`（`render.py:57-182`）：相邻场景同曲不重启；音效响时音乐压低 35%；整体响度归一到 gated RMS 约 -17 dBFS，软限幅到 0.8。
- 各曲节拍：battle 168.75 bpm（拍 0.3556 s）、boss 172.27 bpm（小节 1.3932 s）、title 143.55 bpm（拍 0.418 s、小节 1.672 s）、ominous 71.8 bpm（拍 0.836 s）、travel 120.5 bpm（拍 0.498 s）、tension 108、sad 75.6（3/4）、victory 132.3、ending 91.9。s02 / s04 / s07 / s10 / s12 / s17 的剪辑点都是 `k * BEAT`。
- 音效的“重音偏移”：`sting_reveal` 重击在 +0.26 s、`timestop` 锣在 +0.85 s、`time_resume` 的“啵”在 +1.02 s、`zoom` 峰值 +0.47 s、`tbc` 定格 +1.61 s。所以场景里全是 `at = T - 0.26` 这种提前量（例：`s02:557`、`s15:856,867`）。游戏里播这些音效同样要提前。

## 2. 镜头语言逐项拆解（带参数）

### 2.1 替身召唤 / 常驻光环 / 收回

**`fx.stand_summon(fr, name, x, y, t, t0, flip=False, frame=0, dur=0.35, aura_colour='#c080ff', alpha=0.92, rise=12, scale=1)`**（`fx.py:2383-2423`）

| 阶段 | 做法 |
|---|---|
| `u=(t-t0)/dur < 1` | 竖直位置 `y + rise*(1-ease_out(u))`（从下往上升）；30 Hz 闪烁：`int((t-t0)*30)%2==0 or u>0.55` 时才画；先画光环剪影 `sp.aura(..., alpha=0.7u)`；精灵向白色染 `1-u`，抖动透明度 `alpha*min(1, 0.25+u)`；8 道上升能量线：x 在 ±15 px 内（`hash01(j,3,int(t0*10))`），从 `y-4` 往上走 44 px，长 4–10 px，颜色交替 `aura` / `light(aura,0.6)` |
| `u >= 1` | 常驻：`sp.aura` + 正常画（alpha 0.92）。所以它可以直接当“替身的绘制函数”一直调用 |
| 精灵不存在 | 用程序生成的发光人形 `_figure()` 代替（`fx.py:201`） |

**`sp.aura(img, name, x, y, frame, flip, scale, colour, t, alpha=0.55, grow=1)`**（`sprite.py:268-285`）：1 px 膨胀剪影填光环色，每帧按 `sin(t*23)`、`cos(t*17)` 抖 ±1 px。**先画光环再画替身**。

**`fx.aura_flame(fr, src, x, y, t, frame, flip, colour, seed, grow=3, height=14, scale=1, intensity=1.0, fps=12)`**（`fx.py:2453-2485`）：本体身上往上飘的“气场火焰”（蓄力、DIO 悬浮、承太郎特写）。算法：剪影膨胀 grow 次 + 向上拖 height px 的衰减场（`_aura_fields`，2427-2450），乘一张 64×64 值噪声纹理（`_noise_tex`，292-319，**用 numpy `default_rng(1000+seed)` 生成，JS 不能逐位复现 → 建议构建时把 seed 0–3 四张纹理烘焙成图**），量化成 3 级颜色（dark 0.55 / 原色 / light 0.55）+ Bayer 抖动。**画在精灵之前、同锚点**。

### 2.2 欧拉连打（拳影）

**`fx.rush(fr, x, y, t, t0, t1, direction=1, fist='starplat.fist', spread=26, rate=30, seed=0, colour=None, reach=None, life=0.3, sparks=True)`**（`fx.py:584-647`）

- 第 i 拳出生时刻 `ts = t0 + (i + 0.6*hash01(seed,i,0))/rate`，活 `life`=0.3 s；同屏最多约 `rate*life` ≈ 10 拳。
- 偏移：`ox = spread*0.55*h1`，`oy = spread*((h2+h3)/2-0.5)*1.3`；伸出 `e = ease_out(min(1,u/0.4))`，u>0.75 时回收一半；拳心在 `x + dir*(ox + e*reach)`（reach 默认 `spread*0.75`）。
- 每拳：身后 2 条速度线（长 `6+14(1-u)+6h`，ORA `#d8d0ff` / MUDA `#fff2a0`，逐像素渐隐）、2 个纯色残影（抖动 α 0.35 / 0.6）、按 depth 排序，depth<0.3 的拳暗 30%（远近感）、0.38<u<0.62 时 55% 概率在拳前打出四角星火花（白 + 中心 `#ffd83c`）。
- 拳头精灵 `starplat.fist` / `theworld.fist`（在 `角色图集\starplat\`、`theworld\` 里），不存在时用 `_FIST_GRID` 程序拳（550-572）。

### 2.3 时停（咋瓦鲁多）

**`fx.timestop(fr, t, t0, cx, cy, dur=1.0, tint='yellow', t_end=None, resume_dur=0.6)`**（`fx.py:1846-1883`），内部用 `_sphere_mix`（1819-1843）逐像素按到 (cx,cy) 的距离分“球内 / 球外”处理：

| u=(t-t0)/dur | 画面 |
|---|---|
| 0 – 0.45 | **反色球**从 (cx,cy) 扩散：半径 `R = Rm*ease_out(u/0.45)`，球内 `255-颜色`，球外原样；白色描边 2 px，外面 4 px 处再一圈虚线（调色板倒数第二色，Bayer<0.6）。`Rm = hypot(max(cx,W-cx), max(cy,H-cy)) + 2 + 4`（刚好盖过屏幕最远角） |
| 0.45 – 0.55 | **全屏反色**（R=Rm+10） |

**`timestop_world(fr, amount=1.0, tint)`**（1801-1816）= `_lummap`（261-271）：亮度 `L=(0.299r+0.587g+0.114b)/255`，`L**0.9`，`idx = floor(L*(n-1) + 0.5 + (bayer-0.5)*0.5)` 映射进 6 色调色板（`PALETTES`，241-254）：

### 2.4 冲击帧与“打击感”配方

**`fx.impact_frame(fr, style='invert', threshold=None)`**（`fx.py:437-462`）：整张像素层变高对比漫画格。
- `'invert'`：反色。
- 其它是 2–3 色调色板（`IMPACT`，426-434）：`bw` 黑白、`bw3`、`red` `#16000a #d81c38 #ffe8d8`、`purple` `#1c0832 #8a34d0 #ffe040`、`yellow` `#1a0c00 #e09a18 #fffbe0`、`blue` `#040a24 #2c58e0 #d8f4ff`、`green`。阈值自适应：2 色取亮度**中位数**，3 色取 **38% / 72% 分位**。

**`fx.hit_spark(fr, x, y, t, t0, size=12, colour='white', accent='#ffd83c', seed=0, dur=0.2)`**（465-518）三阶段：u<0.22 大闪光圆（accent 0.55S + 白 0.42S）+ 8 根尖刺（长短交替 1.45/0.9）；u<0.5 圆环 + 更长细刺；之后飞散碎线 + 16 点虚线圈。

**`fx.shockwave(fr, x, y, t, t0, dur=0.4, r_max=60, colour, width=2, squash=1.0, echo=True)`**（521-546）：`r = r_max*ease_out3(u)`，线宽随 u 变细，u>0.55 后抖动淡出；`squash<1` 是地面椭圆；`echo` 内圈 0.72r 再一圈淡的。

## 5. 游戏里过场 / 特写怎么做（建议）

### 5.1 总原则

| 判断 | 走哪条路 |
|---|---|
| 要随玩家操作触发（战斗、必杀、闪避、格挡、受击）、或角色可换（自由走动时换队长） | **JS 实时**（必须） |
| 原片里没有的内容（原片画出来的敌方替身 / 替身使者约 20 个，其中九荣神好几个只在 s12 片头剪影或 2–3 s 小段里出现；第三部全部替身使者都要打） | **JS 实时**（只能这样），复用移植好的“镜头语法” |
| 剧情固定、不可操作、几乎全是场景自绘、台词少，且画面就是原片最好看的那几秒 | **视频**（直接用原工程渲，成本接近零） |
| 剧情固定但台词要扩写（游戏“剧情为主、用对话推进”，台词会比原片多） | 说话部分用**游戏对话系统**，只把中间纯动作那几秒做成**视频插片**（不带音乐，让游戏 BGM 继续） |

### 5.2 必须移植成 JS 的（按优先级）

建议在游戏里做一个 `engine/fx.js`，**函数名和参数顺序跟 Python 保持一致**（`fx.rush(fr, x, y, t, t0, t1, …)`），`fr` 是 `{t, img(320×180 像素缓冲), ui(640×360), zoom(), shake(), flash()}`。这样以后想把原片某个镜头搬进游戏，可以几乎逐行照抄场景代码。

| 优先级 | 原函数（行号） | 游戏里用在哪 | 移植要点 |
|---|---|---|---|
| P0 | `Frame.compose`（core 262-298）+ s10 `camera()` | 所有画面 | 像素层用 320×180 的 `ImageData` / `Uint32Array`；显示时从像素层裁 `W/z × H/z` 的框，`drawImage` 到 ≥640×360 的画布，`imageSmoothingEnabled=false`；UI 层另画在 640×360 上；抖动用“移动 zoom 中心”的写法 |
| P0 | `hash01 / hrange / noise1 / ease / keys / tw / prog / anim / wobble / stepped`（core 69-189） | 一切 | `hash01` 用 `Math.imul` 和 `>>> 0` 做 32 位运算；**Python 对 int 和 float 参数哈希不同**（float 先 `int(round(x*997))`），JS 要分两个入口；Python `round` 是银行家舍入，`.5` 情况会和 `Math.round` 差一点（只影响个别粒子） |
| P0 | Bayer：`BAYER4`（core 302-303）、`_bay`（fx 37-44）、`_paste_dither`（95-106）、`_comp`（83-92） | 所有半透明（原片没有平滑 alpha，全是抖动） | 屏幕对齐：阈值取 `BAYER4[(y)&3][(x)&3]`（+1/32 偏移） |

| P0 | `stand_summon` + `sp.aura` + `aura_flame` + 收回（s02 605-611 / s07 `stand_out`） | J/K/L/U 时替身出现、常驻、收回；蓄力 | 每个精灵帧的“1 px 膨胀剪影”和“向上拖尾场”按 (精灵, 帧, 翻转, 缩放) 缓存；`aura_flame` 的 4 张噪声纹理构建时烘焙 |

## 6. 开场动画（s00 片头 + s01 DIO 复活）怎么渲

### 6.1 为什么不直接跑 `tools\render.py`

`render.py` 的产物路径都写死在 `源码\out\`（`common.py:9` `OUTDIR = os.path.join(ROOT, 'out')`）：分段 `out\segments\<场景>_<宽>.mp4` 和 `list.txt`（27、205-208 行）、`out\_video_<宽>.mp4`、`out\_audio_<宽>.wav`（209、219 行）、`out\timeline.txt`（230 行）；不给 `-o` 时成品是 `out\check_<宽>.mp4`（部分场景）或 `out\jojo_stardust_pixel.mp4`（全片 1920）。**就算给了 `-o`，中间文件也会写进 `源码\out\`**，而且 Python 会在 `源码\tools\`、`engine\`、`scenes\`、`assets\` 下留 `__pycache__`。另外它不出 webm（Playwright 的 Chromium 不带 H.264，银魂踩过这个坑，`银魂\游戏\流程复盘.md` 第 236 行）。

真要用原工具，先整份拷走再跑：

```
robocopy "D:\大疆\游戏素材\JoJo\源码" "%TEMP%\jojo_src" /E
cd /d "%TEMP%\jojo_src"
python tools\render.py --scenes s00,s01 --res 1280 -o "%TEMP%\opening_1280.mp4"
```

参数：`--scenes` 按前缀匹配 `ORDER`（`s00` 匹配 `s00_opening`）；`--res` 是宽度，高 = 宽×9/16（1920 / 1280 / 640）；`--jobs` 默认 `min(12, CPU-2)`，按场景并行；`--crf` 默认 16。输出 H.264（preset medium、crf 16、yuv420p、GOP 48）+ AAC 192k + faststart。

### 6.2 推荐：用不写源码目录的包装脚本

附录 A 的 `render_cutscene.py`（本次在 scratchpad 试跑通过）做的事：把 `源码\` 和 `源码\tools\` 加进 `sys.path`、`sys.dont_write_bytecode = True`，复用 `common.load_scene / render_frame / scene_frames` 逐帧出图（640×360 合成图）直接灌给 ffmpeg，复用 `render.build_audio` 出混音，产物只写到 `--out` 指定的目录；支持 `--range`（从拼接后的时间轴上截一段）、`--no-music`（只混音效，给“插片”用）、`--scale`（1/2/3 倍最近邻）。建议放进游戏的 `游戏\tools\`（或像银魂那样并进 `build_assets.py` 的 `build_video()`，参考 `银魂\游戏\tools\build_assets.py:663-695`）。

### 6.4 输出格式建议

- **分辨率用 1280×720（`--scale 2`）**：640×360 合成图里，像素层每个原像素正好是 2×2 块，和 yuv420p 的色度块对齐，所以像素画本身在 640×360 不会糊；但 UI 文字（描边字、对白）是 1 px 精度，640×360 下色度会把字边弄糊。×2 后每个 UI 像素也变 2×2，文字保持锐利。
- 两份：H.264 mp4（`-preset slow -crf 16 -tune animation -pix_fmt yuv420p`，AAC 160k，`+faststart`）+ VP9 webm（`-crf 30 -b:v 0 -deadline good -cpu-used 4 -row-mt 1`，Opus 128k）。播放时 `canPlayType('video/webm; codecs="vp9, opus"')` 优先 webm（银魂 `engine\script.js:425-470` 的写法），元数据 `{src, webm, duration}` 内嵌进 `data.js`（`file://` 不能 fetch）。
- **游戏画布如果比 640×360 小（比如 320×180 再 CSS 放大），别用 `drawImage` 把视频画进画布**，那样 UI 文字会被缩掉一半分辨率；改成把 `<video>` 元素作为 DOM 覆盖层盖在画布上（同样的 CSS 尺寸，`image-rendering: pixelated`），或者让游戏画布本身就是 ≥640×360。
- 播放细节照银魂：播放前 `stopMusic(0.3)`；把淡出黑幕 `fadeAlpha` 清零、放完还原（银魂踩过“只有声音、画面全黑”的坑，`流程复盘.md` 第 451 行）；0.6 s 后 Enter / 点屏幕可跳过；`ended` / `error` 都要收尾。
- `--no-music` 插片的音效也会被 `build_audio` 响度归一到约 -17 dBFS（实测 mean -14.8 dB），叠在游戏 BGM 上偏响，建议包装脚本里加一个增益参数（例如 -6 dB）或插片时把 BGM 压低。

## 7. 风险 / 坑 / 要定的事

1. **s00 的剪辑点全部踩原片芯片乐 `title`（143.55 bpm：2.299 大字砸下、3.344 起每 1.254 s 一张卡、11.703 全员造型）**。用户指定的标题曲 STAND PROUD 节拍不同，如果把片头视频的音轨换成 STAND PROUD 会错拍。要定：①标题画面放 STAND PROUD，按开始后片头视频用原芯片乐（推荐）；②片头静音、底下放 STAND PROUD（会错拍）；③按 STAND PROUD 的节拍改 s00 的 `T_SLAM / T_ROLL / CARD / T_DODO` 常量重渲（要改源码副本，不改原件）。
2. 视频里的中文台词 / 旁白 / 字幕是烧死的；改剧情就得重渲（很快，十几秒一段），或者把那段改成游戏内对话。
3. `render.py` 会往 `源码\out\` 和 `__pycache__` 写东西 —— 一律用附录 A 的包装或先拷副本。
4. 视频体积：1280×720 约 0.5 MB/s/格式；全部可选片段都做 ≈ 76 MB。要不要两种格式都带、要不要降 crf，需要定。
5. JS 移植的坑：Canvas 抗锯齿（路径、文字）关不掉 → 自己光栅化或二值化；`aura_flame` 的噪声纹理、s00 深空用的是 numpy RNG，JS 复现不了 → 烘焙；`hash01` 的 int / float 区别和银行家舍入；字体在 `file://` 下不方便用 webfont → 粗体字烘焙成图。
6. **闪烁**：原片冲击帧、白闪、黄紫交替很多（s17 18.52–18.95 五次交替），战斗里会更频繁。建议设置里加“减少闪烁”（冲击帧改成只抖屏 + 火花）。
7. 60 Hz 与 24 fps：视频按 24 fps 播放没问题；JS 移植时持续时间统一用秒，冲击帧至少 2 个游戏帧，保留 12 fps 步进。
8. 原片只画了第三部约 20 个敌方替身 / 替身使者（不少只是几秒的蒙太奇）；其余替身使者的 VS 卡、特写切入、招式特效都要靠移植好的 JS 语法 + 补画素材，工作量不在视频这条路上。
9. 本次试跑的脚本和抽帧图都在会话 scratchpad（`C:\Users\yui\AppData\Local\Temp\claude\D----\dd592801-8a86-495b-83a0-71d863169d18\scratchpad\understand\cam09\`），会话删了就没了；附录 A 已经把脚本全文抄进来。

## 附录 A · `render_cutscene.py` 全文（试跑通过；放进 `游戏\tools\` 即可用）

```python
r"""Render one or more JoJo scenes into a game cutscene video (mp4 H.264 + webm VP9),
WITHOUT writing anything into 源码\ (render.py would write 源码\out\).

usage:
  python -B render_cutscene.py --scenes s00,s01 --out OUTDIR --name opening --scale 2
  python -B render_cutscene.py --scenes s00 --range 0 8.2 --name s00a ...

--scale: integer nearest-neighbour upscale of the 640x360 composite (1 -> 640x360, 2 -> 1280x720, 3 -> 1920x1080)
--range: optional [t0, t1) in seconds on the joined timeline (cut a clip out)
"""
import argparse
import os
import subprocess
import sys
import time

sys.dont_write_bytecode = True
SRC = r'D:\大疆\游戏素材\JoJo\源码'
sys.path.insert(0, os.path.join(SRC, 'tools'))
sys.path.insert(0, SRC)

from common import load_scene, render_frame, scene_frames  # noqa: E402
from render import build_audio  # noqa: E402
from engine.core import FPS, UW, UH  # noqa: E402
from PIL import Image  # noqa: E402

ap = argparse.ArgumentParser()
ap.add_argument('--scenes', default='s00,s01')
ap.add_argument('--out', required=True)
ap.add_argument('--name', default='opening')
ap.add_argument('--scale', type=int, default=2)
ap.add_argument('--range', type=float, nargs=2)
ap.add_argument('--no-webm', action='store_true')
ap.add_argument('--no-music', action='store_true', help='SFX only (game BGM keeps playing under the clip)')
a = ap.parse_args()
os.makedirs(a.out, exist_ok=True)

T0 = time.time()
scenes = []
start = 0.0
for nm in a.scenes.split(','):
    name, mod = load_scene(nm)
    if a.no_music:
        mod.MUSIC = None                # in-memory only; build_audio then mixes SFX alone
    n = scene_frames(mod)
    scenes.append([name, mod, start, n, set()])
    start += n / FPS
total = start
r0, r1 = (a.range if a.range else (0.0, total))
ow, oh = UW * a.scale, UH * a.scale

mp4 = os.path.join(a.out, a.name + '.mp4')
vtmp = os.path.join(a.out, a.name + '_v.mp4')
cmd = ['ffmpeg', '-y', '-loglevel', 'error', '-f', 'rawvideo', '-pix_fmt', 'rgb24', '-s', f'{UW}x{UH}',
       '-r', str(FPS), '-i', '-', '-vf', f'scale={ow}:{oh}:flags=neighbor', '-c:v', 'libx264',
       '-preset', 'slow', '-crf', '16', '-tune', 'animation', '-pix_fmt', 'yuv420p', vtmp]
p = subprocess.Popen(cmd, stdin=subprocess.PIPE)
nf = 0
for sc in scenes:
    name, mod, st, n, ev = sc
    for i in range(n):
        tg = st + i / FPS
        fr = render_frame(mod, name, i / FPS, i)
        ev.update(fr.events)            # collect audio cues for the whole scene
        if r0 - 1e-6 <= tg < r1 - 1e-6:
            p.stdin.write(fr.compose().tobytes())
            nf += 1
p.stdin.close()
if p.wait():
    raise SystemExit('ffmpeg video failed')
tv = time.time() - T0

wav = os.path.join(a.out, a.name + '_full.wav')
ok = build_audio([(s[0], s[1], s[2], s[3], sorted(s[4])) for s in scenes], wav)
ta = time.time() - T0 - tv
if ok:
    subprocess.run(['ffmpeg', '-y', '-loglevel', 'error', '-i', vtmp, '-ss', f'{r0:.3f}', '-t', f'{r1 - r0:.3f}',
                    '-i', wav, '-map', '0:v', '-map', '1:a', '-c:v', 'copy', '-c:a', 'aac', '-b:a', '160k',
                    '-movflags', '+faststart', '-shortest', mp4], check=True)
    os.remove(vtmp)
else:
    os.replace(vtmp, mp4)
if not a.no_webm:
    subprocess.run(['ffmpeg', '-y', '-loglevel', 'error', '-i', mp4, '-c:v', 'libvpx-vp9', '-crf', '30', '-b:v', '0',
                    '-deadline', 'good', '-cpu-used', '4', '-row-mt', '1', '-c:a', 'libopus', '-b:a', '128k',
                    os.path.join(a.out, a.name + '.webm')], check=True)
print(f'{a.name}: {nf} frames {ow}x{oh}, video {tv:.1f}s, audio {ta:.1f}s, total {time.time() - T0:.1f}s')
for ext in ('.mp4', '.webm'):
    f = os.path.join(a.out, a.name + ext)
    if os.path.exists(f):
        print(f'  {f}  {os.path.getsize(f) / 1e6:.2f} MB')
```

注意：
- 留下的 `<name>_full.wav` 是整段混音（截片时比视频长），用完可删；正式版可以改成写到临时目录。
- `--range` 最好给帧格时刻（`k/24`）；音频按 `-ss r0` 截，和画面最多差 1 帧。
- `mod.MUSIC = None` 只改内存里的模块对象，不碰源码文件。
