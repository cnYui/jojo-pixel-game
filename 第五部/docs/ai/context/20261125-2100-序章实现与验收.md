# 序章实现与验收

范围严格限于开发脚本第 3 节。第 1 章保留原骨架，只作为序章结束后的入口；没有实现第 1 章或恢复其他暂停计划，没有修改第四部、公共引擎及第三部输出。

默认背景裁切由 `assets/bg_src/offsets.json` 保存，机场出口 128、缆车车厢 80。命令行 `--crop-y` 可单键覆盖，配置本身不变。

序章接入篇章卡、地图图钉和红章、机场电话过场、五处 E 调查和 45 秒出口箭头、出租车带走行李、康一名牌与回音 ACT3 卡、出租车战、警官收纸币、乔鲁诺名牌与黄金体验卡、行李箱变青蛙跳走、康一旁白和 To Be Continued，之后从现成菜单继续进入第 1 章。

出租车是 `prop:taxi`，低耐久切换 `taxi_hit`。战斗使用现成 `S.fight`、物件受击、危害预警、能量与必杀、失败菜单和重试。康一 100 HP；车耐久 280；J 三连与连打削减耐久；U 消耗能量削减 60，并压低车身、停止倒车 4 秒；倒车预警 0.9 秒，实际伤害判定跟随车身。K 或走出车道均可躲避。失败重试恢复玩家、耐久、机关与能量。

`tools/p5_ui.py` 只读导入第四部 `p4_ui` 的生成函数，将输出和字体缓存重定向到本部。名牌、替身卡、地点卡、地图红章、ACT3 拟声字和必杀字随 `build_p5.py` 生成。没有重写对话或卡片引擎。

验证使用 Python 3.12（`PYTHONUTF8=1`）、Node 24，以及 `NODE_PATH=D:/CodeWorkSpace/honglou-juan2/node_modules` 中已有的 Playwright，没有安装包。复用字体仅缓存到本部被忽略的目录。
