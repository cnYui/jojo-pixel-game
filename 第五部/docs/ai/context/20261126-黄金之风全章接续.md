# 黄金之风全章接续

在 `claude/p5-golden-wind` 的现有序章和第 1 章上接入第 2–8 章与罗马终章。篇章沿用原开发脚本的顺序，第 2 章起按通关记录解锁。旧序章与第 1 章仍可在新存档试玩，保存键仍是 `p5-progress`，完成终章会写入 `clear`。

后续篇章的过场、探索和战斗编排在 `游戏/story/p5_ep_*.js`；`p5_campaign.js` 调用原生自由移动、对话、按键、战斗和重试，处理突袭、冲刺、范围预警、远程射击以及镇魂曲。改编按篇章主线收束，个别原作支线及演出以旁白表现，没有新增付费、发布或外部服务。

九张生成像素背景切成独立的 `assets/bg_src/p5_*.png`，用 `tools/bg_p5.py` 裁切、量化并登记分包。银色战车镇魂曲是透明的场景剪影，脚底锚点 [15, 48]，黄金体验镇魂曲仍用已在分支中的角色资产。原有角色和替身图未重画。

运行（本文件路径相对于仓库根目录）：

```bash
python 第五部/tools/dev/p5_serve.py
```

已有 `游戏/data` 包可直接测试，不需要重新构建。修改台词或素材后的常用验证：

```bash
python 第五部/tools/dev/locked_build.py data check
node 第五部/tools/dev/p5_smoke.js
node 第五部/tools/dev/p5_regression.js
node 第五部/tools/dev/p5_play.js
```

Python 需要 Pillow；JS 浏览器检查需要能够加载 Playwright 的 Node 及 Chromium。浏览器包可以按本机路径设 `NODE_PATH` 和 `PLAYWRIGHT_BROWSERS_PATH`。背景源改动后先运行 `python 第五部/tools/bg_p5.py`。默认构建复用已经检入的序章/第 1 章美术与道具，避免重新下载原 UI 字体。确实要重烘初始道具和装饰卡时才传 `python 第五部/tools/build_p5.py --rebuild-art`。验收报告写在 `第五部/tools/dev/_out/`。

本次验收：102 项资源合同、89 项公共战斗回归、标题/暂停/锁章冒烟均通过。真实键盘从序章连续完成 19 场战斗，验证故意失败后的重试、新必杀、8 个新篇章通关标记以及终章重载存档，未发现浏览器错误、请求失败、缺图、缺字或替代动作。解压后的独立交付包在 Chromium 也能启动标题并登记全部 10 个可玩章节。
