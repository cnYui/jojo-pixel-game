# 素材导出接口

`python 第五部/tools/export_p5.py` 导出 cast5_heroes、cast5_villains、cast5_stands 的全部人物与替身，共46个原画图集。原始画法不变；在导出器中将 px.ASSETS 与 portrait.ASSETS 绑定到当前第五部/assets，按 Sheet.pack/anims/top 写第四部同格式元数据，原画为30像素规格，因此 k=1。

额外人物接口为 CAST / build(cid)，道具接口为 PROPS = {id: 无参数函数}，函数返回 px.Cv。可选模块存在时自动使用，未提供的固定 id 按30像素人物或比例表道具色块补齐。当前4个额外人物和5个道具均为占位。

动作映射的完整优先表在 export_p5.py 的 ACTION_CANDIDATES；已画出的同名动作不覆盖。主要回退：cmd/cmd2/cmd_hold→pose（有point则point）、talk→idle、dodge→run或walk、getup→hurt、special→dream或pose、punch/punch2→attack、punch_heavy/upper→kick或punch或attack、rush→punch或attack、reach/fist→punch或attack或pose、block→guard或pose。每个人最终实际使用的 amap 另写 assets/_meta/action_aliases.json，所有目标都是现有动作，不在原图上复制或补画。

运行导出成功：50个图集、400张对话头像、5个道具。康一、承太郎、ACT3将在构建时从第四部读取，不在这里改写原素材。
