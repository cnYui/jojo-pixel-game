# 构建与启动

`build_p5.py` 先重烘12/16px字库，字表覆盖第三部公共字表、第五部入口/引擎/story、第五部开发脚本。沿用第四部文泉驿正黑点阵index=1、白字透明图集、64列及相同行高；Windows首次构建从Debian公开字体源下载字体数据到本部 tools/font_cache，后续离线复用；可用 P5_FONT 指定已有同款字体文件。没有安装任何Python或Node包。

第三部特效、拟声字、通用UI、白金之星、SFX及6首芯片音乐从仓库根 data 只读复用。第四部 chars*.json 按既有顺序合并后，取 koichi/jotaro4/echoes3 的最新图集与头像，从第四部/assets直接读入第五部data包；康一的替身设为echoes3。用户音频不登记，旧构建多余的音乐脚本也会清除。

数据采用core与bg_common/bg_title/bg_prologue/bg_ch1分包，元数据引用缺图时构建直接失败。篇章卡和标题标志用同一字库生成，后续按章节的chars_*/props_*/bg_*/ui_*元数据仍支持深合并。

第一次构建通过：584张图片、54个角色、10个背景、5个资源包。浏览器已通过标题、序章卡、机场真实方向键移动、暂停回标题、灰章不可确认、第1章独立入口与移动，控制台0错误、缺图/头像/字/SFX均为0。

根目录locked_build.py会创建根tools/_build.lock并重写第三部data，与本任务“只允许修改第五部”的边界冲突，因此不执行该根构建。第五部构建自身执行引用合同校验；公共战斗引擎将用只在本部输出的夹具回归检查。
