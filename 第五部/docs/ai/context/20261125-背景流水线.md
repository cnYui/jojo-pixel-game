# 背景流水线

`python 第五部/tools/bg_p5.py` 为开发脚本第2节的全部十个背景键生成 assets/bg/键/base.png，并写 assets/_meta/bg.json。固定高180，宽度按表；ground=150、walk=[142,176]，室内墙脚138、天花66。anchors 包含入口、出口、初始位置、横向可走范围与比例线，具体交互坐标由剧情任务追加。

放入 assets/bg_src/背景键.png 后再次执行即可替换占位图。采用等比裁切、BOX缩小、无抖动64色量化，不拉伸宽高比。`--crop-y airport_hall=80 funicular_car=-30` 可把源图裁切框向下80或向上30源图像素（超出边界夹紧；整高裁切时纵向不可移动）；可重复传入 --crop-y，`--sharpen` 可选轻度锐化。

尚无源图时使用室内天花/墙面/地板或室外天空/地平面占位，并按任务要求写地图id字母；正式生成背景不额外添加文字。当前十个背景均为占位。
