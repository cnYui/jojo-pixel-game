## 3. 序章　那不勒斯 / 黄金之风

1. 篇章卡（`map_pro`）：「序章　那不勒斯」副标题「黄金之风」。地图两枚图钉「机场」「老城区」，红章「2001年3月」，右上小字「意大利 那不勒斯」。
2. 过场（`airin_pro`，BGM daily）。康一旁白：
   - 「2001 年，意大利。我是广濑康一，这次一个人坐飞机来到了那不勒斯。」
   - 承太郎（电话）normal：「康一君，我要你确认一个少年。名字叫汐华初流乃，十五岁。」
   - 康一 normal：「承太郎先生，他是什么人？」
   - 承太郎：「……也许和 DIO 有血缘。取到一点他的皮肤细胞就行，不要打草惊蛇。」
   - 康一 shock：「DIO……！好、好的，我试试看。」
3. 自由走动（`airin_pro`，队长康一）。E 调查：问讯台、航班屏、两个路人、行李转盘；走到右端出机场。45 s 后箭头指右。
4. 过场（`airout_pro`）。乔鲁诺装成出租车司机：
   - 乔鲁诺 smile：「这位客人，进城吗？行李我帮你放后备箱。」
   - 康一 smile：「啊，谢谢你，你的意大利语……不对，你会说日语？」
   - 乔鲁诺 normal：「一点点。」（车开走，行李带走了）
   - 康一 shock：「等一下！我的行李！我的护照还在里面！」
   - 名牌「广濑康一」+ 替身卡「回音 ACT3」。
5. 战斗 序1「别想开走」（`airout_pro`，玩家 = 康一 + 回音 ACT3，对手 = 出租车）。目标不是打倒人：出租车有“耐久”，每次 J 连击或 U（3 FREEZE，重力压住车身，车下沉、动不了 4 s）削减；车会倒车冲撞（有地面预警，K 闪避）。耐久归零胜利。教学：J 连打、K 闪避、U 必杀。康一 HP 100。
6. 过场：警官过来盘问（`police` normal）：「喂，这里不让停车！」乔鲁诺把车停下，递过去一张纸币，警官转身走开。康一看呆。
   - 乔鲁诺 normal：「对不起，行李我只能收下了。」
   - 黄金体验出现（名牌「乔鲁诺·乔巴拿」+ 替身卡「黄金体验」）：行李箱变成一只青蛙跳走。
   - 康一 shock：「行李……变成青蛙了？！他也是替身使者！」
   - 乔鲁诺走远；康一旁白：「那个侧脸，和照片上的汐华初流乃一模一样。」
7. To Be Continued → 第1章。

## 4. 第1章　街头干部 / 布加拉提登场

1. 篇章卡。过场（`street_ch1`）：乔鲁诺旁白两句（他想成为黑帮里的明星，要改掉让孩子沾毒品的帮派）。
2. 自由走动（队长乔鲁诺，U = 黄金体验“赋予生命”：对着指定物件按 U 把它变成动植物）：
   - 花盆 → 长出藤蔓；碎石 → 变成青蛙；长椅上的钥匙 → 蝴蝶（飞回失主那里，失主道谢）；其他东西：「这个不需要生命。」
   - 路人两处对话提到“街头干部布加拉提在查什么人”。走到右端 → 3。
3. 过场（`cafe_ch1`）泪眼卢卡拦路：
   - 卢卡 rage：「小鬼，机场那一带是我的地盘。你拉客不交钱？呜……我看着都心酸。」
   - 乔鲁诺 normal：「我拒绝。」
   - 卢卡抡铲子打向地上的青蛙，黄金体验的能力让伤害弹回他自己身上，卢卡倒地（不见血）。
   - 乔鲁诺：「打它的那一下，会原样回到打的人身上。」
4. 过场（`station_ch1` → `car_ch1`）：缆车里，布加拉提坐到乔鲁诺旁边。
   - 布加拉提 normal：「卢卡住院了。有人看见他和一个金发少年说话。你认识他吗？」
   - 乔鲁诺：「不认识。」
   - 布加拉提 smile：「是吗。我只要尝一下汗的味道，就知道人有没有撒谎。」（舔脸颊的动作用剪影加“……！”表现，克制处理）
   - 布加拉提 rage：「——这是撒谎的味道。」→ 名牌「布加拉提」+ 替身卡「钢链手指」→ VS 卡。
5. 战斗 ch1-1「车厢」（`car_ch1`，乔鲁诺 vs 布加拉提）：场地窄。布加拉提招式：直拳连打；拉链拳（伸长拳，地面预警长条，K 闪或 L 弹反）；钻进拉链消失后从另一侧出现。打到对方 HP 40% 结束，进过场。乔鲁诺 HP 120，布加拉提 HP 140。
6. 过场（`square_ch1`）：两人冲到广场。乔鲁诺把掉落的牙齿大小的小物件变成苍蝇追踪布加拉提（画成小虫光点）。
7. 战斗 ch1-2「拉链」（`square_ch1`）：布加拉提新招：地面开拉链口（踩上去硬直，口子闭合前走开）；远端伸手抓脚踝。乔鲁诺新招 U（能量满）：黄金体验让对手“感觉失控”——对手 3 s 慢动作（画面泛白、残影）。打到 HP 归零。
8. 过场（`harbor_ch1`，黄昏）：
   - 布加拉提 normal：「为什么手下留情？」
   - 乔鲁诺 normal：「因为你刚才为了一个孩子手里的毒品生气。你不是那种人。」
   - 乔鲁诺 rage：「我，乔鲁诺·乔巴拿，有一个梦想。」
   - 乔鲁诺 smile：「我要成为黑帮里的明星。」
   - 布加拉提沉默很久，smile：「……想进组织，先过干部波尔波那一关。跟我来。」
